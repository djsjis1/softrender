# 34 · 骨骼动画与蒙皮

> 角色动画的核心：骨骼层级驱动网格变形。每个顶点绑定最多 4 根骨骼，每帧根据动画关键帧插值骨骼变换，加权混合得到蒙皮后的顶点位置。本篇讲数据结构、每帧流程、LBS 公式，以及 glTF 动画采样的实现细节。

## 一、数据结构

```
Skeleton
  └── Bone[]
        ├── name
        ├── parent (index)
        ├── localTransform (bind pose)
        └── inverseBindMatrix

VertexBoneWeights
  ├── boneIndices[4]
  └── weights[4]

Animation
  └── AnimationChannel[]
        ├── boneIndex
        └── Keyframe[] (time, translation, rotation, scale)
```

## 二、每帧流程

1. **采样动画**：对每个 channel，在当前时间二分查找相邻关键帧，插值得到局部变换
2. **计算全局变换**：按父链上溯 `global[i] = global[parent] * local[i]`
3. **蒙皮矩阵**：`skin[i] = global[i] * inverseBindMatrix[i]`
4. **顶点蒙皮**：`skinnedPos = Σ weight_j * skin[bone_j] * bindPos`

## 三、线性混合蒙皮（LBS）

$$p' = \sum_{j=0}^{3} w_j \cdot M_j \cdot p$$

其中 $M_j$ 是第 $j$ 根骨骼的蒙皮矩阵，$w_j$ 是权重（$\sum w_j = 1$）。法线同理，但用 `transformDir`（只旋转不平移）。

## 四、glTF 动画采样

动画采用 channels + samplers：channel 指定节点与 TRS 分量，sampler 指向时间和数值 accessor。

| 模式 | 行为 |
| --- | --- |
| LINEAR | 位移/缩放线性插值，旋转先归一化再做最短弧 SLERP |
| STEP | 取当前区间左端关键帧；恰好命中下一个时间戳时取新帧 |
| CUBICSPLINE | 每帧读取入切线、数值、出切线三元组，Hermite 切线乘以时间间隔，旋转结果归一化 |

时间超出有效区间时钳制到首/末帧，不自动循环。输入必须是非负、有限、严格递增的 FLOAT SCALAR；
输出必须匹配路径与帧数，三次样条输出数量是时间戳数量的三倍。平移/缩放使用 FLOAT VEC3，
旋转使用 FLOAT 或归一化整数 VEC4。动画 accessor 必须紧密存放。零四元数、非有限采样结果、错误下标和截断字节均返回失败。

`sampleChannel` 支持上述三种模式，失败返回 false 且不改变输出；`sampleAnimation` 将成功结果合并到各节点 bind pose，
并设置 hasTranslation/hasRotation/hasScale。`AnimSample::nodeIndex` 默认 -1，采样失败不会误合并到随机节点。

### 解析一次，反复采样

动画结果只保留 accessor 编号，必须同时保存对应的 `tinygltf::Model`。下面的 model 与转换结果来自同一次解析，
不能用另一个文件或重新排列过 accessor 的模型替换。

```cpp
#include <softrenderer/scene/gltf_loader.h>

tinygltf::Model model;
tinygltf::TinyGLTF loader;
std::string error, warning;
if (!loader.LoadBinaryFromFile(&model, &error, &warning, "animated.glb")) {
    report(error);
    return;
}
auto result = sr::gltf::convertModel(model);
if (!result.success || result.animations.empty()) return;

auto samples = sampleAnimation(model, result.animations.front(), elapsedSeconds);
for (const auto& sample : samples) {
    Mat4 local = animSampleToMatrix(sample);
    // 节点层级、全局关节变换和蒙皮权重由调用方继续求值。
}
```

当前每次采样校验完整时间序列，再读所需数值；不分配逐通道时间数组，也不缓存可变模型的裸地址。
大规模角色的下一步是显式拥有数据的预编译动画缓存，以避免重复 O(关键帧数) 校验；当前没有该性能优化的测量结论。

## 六、限制与进阶方向

- `examples/demo_skinning.cpp` 生成两关节测试模型并输出逐帧图像；逆绑定矩阵按 glTF 列主序转换到内部行主序。它是手工单关节演示，不是通用层级蒙皮导入器。
- 动画混合、状态机、morph weights 与完整 skin 场景求值仍待实现。
- 进阶方向：对偶四元数蒙皮（DQS）解决 LBS 的"糖果纸"收缩；多动画按权重叠加；预编译动画缓存。
