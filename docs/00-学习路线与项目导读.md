# 00 · 学习路线与项目导读

> 这份文档是入口。它告诉你：按什么顺序读源码、每个阶段要理解哪些文件、在哪里练习。

## 一、这个项目是什么

**纯 CPU 手写的软光栅渲染器**：不借助 OpenGL / DirectX / Vulkan，把"给一堆 3D 三角形 + 相机 + 光源，算出屏幕每个像素的颜色"从头实现一遍。这正是显卡内部做的事。

核心设计：
- **可读性优先于性能**：每行代码对应一条图形学原理
- **核心计算与平台隔离**：`include/` 与 `src/` 不引用任何平台代码，`platform/` 是可选显示层
- **第三方库以源码集成**：`third/` 目录，随项目一起编译，无需额外安装

## 二、学习方法

**核心原则：读源码学原理，写代码练手艺，看示例作参考。**

每个阶段的学习步骤：

1. **读源码**（`include/softrenderer/`）：打开指定的头文件，从头注释开始读，理解数据结构和算法
2. **读文档**（`docs/`）：配合 `pipeline/` 或 `advanced/` 中的理论文档
3. **写练习**（`practice/`）：自己动手实现，把理解变成代码
4. **看参考**（`examples/`）：卡住时参考示例代码，不要照着抄

> `examples/` 是参考答案，不是教材。先看源码、先自己写，实在卡住了再翻。

## 四、练习目录

`practice/` 是你的实验场：

```
practice/
├── hello_2d.cpp          ← 入门模板（复制它开始新练习）
└── your_practice.cpp     ← 你的练习代码
```

**练习规范**：
- 每个 `.cpp` 是一个独立程序，CMake 自动识别
- 输出到 `output/` 目录（TGA/PNG 格式）
- 实时窗口练习需加 `#include "platform/win32_window.h"`

## 七、项目结构

```
softrender/
├── include/softrenderer/   ★ 渲染器本体（公共头，C++23）← 主要学习材料
│   ├── math/       向量、矩阵、四元数、矩形、2D/3D 变换
│   ├── core/       帧缓冲/深度/MSAA/浮点缓冲/G-Buffer/图像/颜色/混合/内存池
│   ├── render/     pipeline（Renderer·裁剪·Shader·队列·MSAA）
│   │               raster（三角形·覆盖规则·SIMD 光栅）
│   │               shader（Flat/Gouraud/Phong/PBR/阴影/延迟）
│   │               postprocess（Bloom·SSAO·FXAA·DOF·色调映射）
│   │               draw2d（shape2d·blit2d·Renderer2D）
│   ├── resource/   网格/纹理/立方体贴图/生成器/顶点
│   ├── runtime/    线程池/命令缓冲/Profiler/资源缓存/日志
│   ├── scene/      相机/节点/材质/骨骼/动画/粒子/ECS 组件
│   └── io/         OBJ/glTF/TGA/图像读写接口（实现见 src/io/）
├── src/io/                 文件加载实现（softrenderer_io 静态库）
├── platform/               平台显示层（Win32 GDI 窗口）
├── practice/               ★ 你的练习代码写在这里
├── examples/               参考实现（卡住时再看）
├── tests/                  GoogleTest + 像素回归 + 下游消费工程
├── benchmarks/             基准与压测探针
├── third/                  第三方库源码
└── docs/                   本套文档
```

## 八、构建与运行

```powershell
# 配置 + 编译
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --parallel

# 运行你的练习
.\build\bin\Release\practice_xxx.exe

# 运行参考示例（卡住时参考）
.\build\bin\Release\stage01_framebuffer.exe

# 运行全部测试
.\build\bin\Release\unit_tests.exe
```

输出图像在 `output/` 目录（TGA / PNG，多数看图软件可打开）。

## 九、2D 子系统速查

项目有完整的 2D 渲染子系统（`sr::draw2d`），与 3D 管线**共用同一个 Framebuffer**：

| 模块 | 核心文件 | 职责 |
|------|----------|------|
| 矢量图元 | `render/draw2d/shape2d.h` | 矩形/圆/椭圆/多边形/圆角矩形 |
| 图像合成 | `render/draw2d/blit2d.h` | 缩放/旋转/仿射变换/精灵 |
| 2D 渲染器 | `render/draw2d/renderer2d.h` | 变换栈、Camera2D、scissor、字体 |
| 混合模式 | `core/blend.h` | Opaque/AlphaBlend/Additive/Multiply |

**两条红线**：
1. `Framebuffer` 坐标约定不可修改（y 向上，左下角原点）
2. `draw2d::plotBlend` 是 2D 唯一像素写入出口
