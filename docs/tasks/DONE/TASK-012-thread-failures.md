## 设计

保留 submit(void task)，任务异常捕获后由 waitAll 在排空队列时报告首个错误；增加 submitFuture 支持结果值、移动捕获与单任务异常。
命令并行回放捕获回调异常，等待全部线程结束后在调用线程报告。异常不会逃出工作线程。
构造部分线程失败时停止并 join 已启动线程；析构排空已接受任务。拒绝空任务和池内 worker 调用自身 waitAll。

替代方案是吞掉异常后继续运行，或让现有 submit 改为 future；前者不可观测，后者使旧代码忽略错误，均不采用。
详见 ADR-002。不承诺任务取消、强制终止、不受限制的递归等待或与对象析构并发调用成员函数。
