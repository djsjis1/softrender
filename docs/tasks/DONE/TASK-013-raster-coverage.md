## 方案与设计

A：仅在每个浮点循环增加 top-left 等号判断，改动小，但不同起点和累加误差会使共享边判断漂移。
B：统一 1/256 像素量化、int64 覆盖边方程，采用方案 B。覆盖与浮点属性插值分离，SSE2 用整数边掩码。
输入坐标限制为绝对值不超过 2^20 像素，保证边乘法和增量不会溢出。退化、非有限、范围外输入不绘制。
屏幕 y 向上，顶边和左边含等号；反绕序归一化。MSAA 仅向覆盖且通过逐样本深度测试的槽写颜色。
