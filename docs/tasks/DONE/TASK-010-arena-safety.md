## 分析与设计

零初始容量使翻倍扩容不能前进；align 未校验，sizeof(T)*count、size+align 与扩容翻倍
可能溢出；超出对象的指针加法也不安全。raw new 后 vector 扩容异常会泄漏。
reset 每帧删除扩展块，重复负载每帧重新申请。

方案 A：只补算术检查。改动较小，但重复分配仍在。
方案 B（采用）：块使用 unique_ptr 管理，尺寸检查后分配；reset 只重置游标并复用已有块。
保留 alloc/allocArray/reset/used 接口，无效请求返回 nullptr，真实内存不足仍由 new 抛出。
零容量视为最小容量。reset 后所有既有指针失效，容量保留到析构，内存占用按峰值保留。
