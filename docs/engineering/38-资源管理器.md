# 38 · 资源管理器

> 纹理/网格等资源全局只加载一次，引用计数归零自动释放，线程安全。

## 一、设计

- **缓存**：`weak_ptr` 存储，`shared_ptr` 返回。引用归零后 `purge()` 清除。
- **线程安全**：`std::mutex` 保护缓存 map。
- **模板化**：`load<Texture>(path)` / `load<Mesh>(path)` 通用。

## 二、用法

```cpp
auto tex = ResourceManager::instance().load<Texture>("brick.png");
// tex 是 shared_ptr<Texture>，离开作用域自动减引用
ResourceManager::instance().purge(); // 帧末清除过期缓存
```

`include/softrenderer/runtime/resource_cache.h`
