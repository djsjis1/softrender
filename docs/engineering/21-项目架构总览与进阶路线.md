## 三、进阶路线（通向企业级）

以下是从"教学渲染器"到"生产级引擎"的典型差距，按优先级排列：

### 性能
- [ ] **SIMD 光栅化**：用 SSE2/AVX 对 4/8 像素同时算重心坐标+深度测试
- [ ] **Tile-based 渲染**：把屏幕分成 16×16 tile，每 tile 独立光栅化+深度，缓存友好
- [ ] **增量式边函数**：包围盒内逐行递推边函数值，避免每像素重算叉积
- [ ] **Early-Z**：深度测试提前到片元着色之前

### 功能
- [ ] **IBL（图像光照）**：cubemap 环境反射 + 预滤波 + 辐照度图
- [ ] **级联阴影贴图（CSM）**：大场景分多级 shadow map
- [ ] **透明混合**：alpha blend + 排序渲染
- [ ] **骨骼动画**：顶点蒙皮 + 关节矩阵
- [ ] **粒子系统**：billboard + 发射器
- [ ] **延迟渲染**：G-Buffer + 光照 pass

### 工程
- [ ] **ECS 架构**：Entity-Component-System 管理场景
- [ ] **资源管理器**：异步加载 + 引用计数 + 缓存
- [ ] **多线程命令缓冲**：录制 DrawCommand，多线程回放
- [ ] **Vulkan/Metal 后端**：把 Renderer 接口对接 GPU API
- [ ] **热重载 Shader**：文件监听 + 重编译

### 质量
- [ ] **像素回归测试**：固定场景输出哈希对比
- [ ] **性能基准**：google-benchmark 测量各 pass 耗时
- [ ] **内存追踪**：自定义 allocator 统计峰值/泄漏
- [ ] **跨平台 CI**：GitHub Actions 跑 Linux + Windows + macOS

从一行 `setPixel` 到 PBR + 阴影 + SSAO + 多线程 + 35 个单元测试，你已经亲手走过了实时渲染管线的每一个环节。这不是"调 API"能给你的理解——你**造过轮子**，所以你知道轮子为什么是圆的。
