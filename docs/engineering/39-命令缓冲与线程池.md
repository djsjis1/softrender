# 39 · 命令缓冲与线程池

> 录制渲染命令，多线程并行回放。参考 Vulkan CommandBuffer 思想。
>
> ⚠️ 两个类均位于 **`namespace sr`**（ADR-001 第 2 批），下文代码已加 `sr::` 前缀。
> 写完整程序时也可在 include 之后加 `using namespace sr;` 免去逐处限定。

## 一、sr::CommandBuffer

```cpp
sr::CommandBuffer cmd;
cmd.record([&]() { renderer.drawMesh(mesh1, shader1); });
cmd.record([&]() { renderer.drawMesh(mesh2, shader2); });
cmd.executeParallel(4); // 4 线程并行
```

命令间必须无数据依赖（不同物体/不同 tile）。

## 二、sr::ThreadPool

避免每帧创建/销毁线程：

```cpp
sr::ThreadPool pool(8); // 8 工作线程
pool.submit([&]() { /* 任务 */ });
pool.waitAll(); // 等待全部完成
```

> 线程池的退出标志 `stop_` 已声明即初始化（`= false`）。它是工作线程构造后
> **立即读取**的字段，未初始化的值叠加多线程会表现为难重现的偶发挂死或
> 提前退出 —— 对应 `engineering_rules.md`「线程必须有明确生命周期与可控退出标志」。
