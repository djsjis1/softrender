# 46 · 构建与使用指南

> 从零开始构建、测试、使用本渲染器的完整指南。

## 一、环境要求

- C++17 编译器（MSVC 2019+、GCC 9+、Clang 10+）
- CMake 3.16+
- 无其他系统依赖（所有第三方库源码在 `third/`）

## 二、构建

```bash
# 配置
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release

# 编译全部
cmake --build build --config Release --parallel

# 只编译测试
cmake --build build --config Release --target unit_tests
```

Windows + Visual Studio：
```bash
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

## 三、运行测试

```bash
ctest --test-dir build --build-config Release --output-on-failure
# 或直接
./build/bin/Release/unit_tests
```

## 四、运行示例

```bash
# 离屏渲染（输出 TGA 到 output/）
./build/bin/Release/stage8_offline

# 实时窗口（Windows）
./build/bin/Release/stage8_realtime
```

## 五、作为库使用

### 方式 1：add_subdirectory

```cmake
add_subdirectory(path/to/渲染器)
target_link_libraries(myapp PRIVATE SoftRenderer::softrenderer)
```

### 方式 2：find_package（安装后）

```bash
cmake --install build --prefix /usr/local
```

```cmake
find_package(SoftRenderer REQUIRED)
target_link_libraries(myapp PRIVATE SoftRenderer::softrenderer)
```

### 方式 3：手动 include

```cmake
include_directories(path/to/softrender/src)
include_directories(path/to/softrender/third/stb)
include_directories(path/to/softrender/third/tinygltf)
include_directories(path/to/softrender/third/nlohmann)
include_directories(path/to/softrender/third/entt/src)
# 编译 third/tinygltf/tiny_gltf_impl.cpp 和 third/tiny_obj_loader_impl.cpp
```

## 六、CMake 选项

| 选项 | 默认 | 说明 |
|---|---|---|
| `SR_ENABLE_SPDLOG` | ON | 启用 spdlog 日志 |
| `CMAKE_BUILD_TYPE` | Release | Debug/Release/RelWithDebInfo |

## 七、中文路径问题

CMake 对含中文的路径可能崩溃。解决方案：
```powershell
# Windows：创建 junction 软链接
New-Item -ItemType Junction -Path D:\softrender -Target "d:\code\.std\渲染器"
cd D:\softrender
cmake -S . -B build ...
```

## 八、CI

推送到 GitHub 后，`.github/workflows/ci.yml` 自动在 Windows/Linux/macOS 上构建+测试。
