# 37 · 四元数与旋转插值

> 欧拉角有万向节锁问题，矩阵插值会产生缩放变形。四元数是旋转插值的正确工具。

## 一、为什么自己写

四元数与 `Vec3f`/`Mat4` 紧耦合（`rotate(Vec3f)`、`toMat4()`），用外部库（如 GLM 的 `glm::quat`）会导致类型不兼容。且四元数只有 ~100 行，是渲染核心数学。

## 二、核心操作

| 操作 | 函数 |
|---|---|
| 轴角→四元数 | `Quat::fromAxisAngle(axis, angle)` |
| 欧拉角→四元数 | `Quat::fromEuler(yaw, pitch, roll)` |
| 旋转向量 | `q.rotate(v)` |
| 转矩阵 | `q.toMat4()` |
| 球面插值 | `slerp(a, b, t)` |
| 归一化线性插值 | `nlerp(a, b, t)` |

## 三、SLERP vs NLERP

- **SLERP**：恒角速度，精确，稍贵（acos + sin）
- **NLERP**：非恒速，但快得多（只 lerp + normalize），视觉差异极小

游戏引擎通常用 NLERP，电影级动画用 SLERP。
