# 44 · 第三方库总览

> 所有第三方库统一放在 `third/` 目录，通过 CMake `add_subdirectory` 或静态库集成。核心光栅化与数学（`src/math/`、`src/raster/`）不依赖第三方；场景加载与 ECS 依赖仓库内置第三方代码。

## 编译组织

所有需要 `.cpp` 实现的库统一编译为一个静态库 `third_party_impl`：

- `src/io/stb_impl.cpp`（含 stb_image + stb_image_write 实现）
- `src/io/tinygltf_impl.cpp`（含 tinygltf 实现）
- `src/io/tinyobj_impl.cpp`（含 tinyobjloader 实现）

header-only 库（EnTT）用 INTERFACE 目标。

## 添加新库的流程

1. 下载源码到 `third/<name>/`
2. 创建 `*_impl.cpp`（如需）
3. CMake 加入 `third_party_impl` 或新建 INTERFACE 目标
4. 更新 `install.cmake`
5. 更新本文档
