# 27 · 像素级回归测试

> 单元测试验证算法正确性，但渲染器的最终输出是**图像**。像素级回归测试确保"同样的输入永远产生同样的画面"——任何重构导致的视觉回归都能被自动捕获。

## 一、工作流程

1. **首次运行**：渲染固定场景，保存输出为基准图（golden image）到 `tests/golden/<name>.tga`。
2. **后续运行**：渲染同一场景，逐像素对比输出与基准图。
3. **判定**：不匹配像素 < 0.1% 且平均差 < 0.5 灰度 → 通过。

## 二、容差设计

为什么允许少量偏差？

- 浮点精度：不同编译器/优化级别可能产生 ±1 灰度差异
- 抗锯齿：MSAA/FXAA 的亚像素采样对浮点顺序敏感
- 平台差异：Linux vs Windows 的 `std::sin` 实现可能差 ULP

所以阈值设为 2 灰度/像素、0.1% 像素不匹配率。超过即为**真回归**。

## 三、对应代码

| 概念 | 代码 |
|---|---|
| 比较函数 | `test/pixel_regression.h`：`regression::compare` |
| 保存基准 | `regression::saveGolden(name, fb)` |
| 加载+比较 | `regression::compareWithGolden(name, fb)` |
| 统计结构 | `CompareResult`（passed, mismatchRatio, maxDelta, avgDelta） |

## 四、CI 集成

```yaml
- name: Pixel regression
  run: |
    ./build/bin/stage8_offline
    ./build/bin/pixel_regression_tests  # 对比 golden/
```

基准图提交到 Git（TGA 无损，体积可控）。若 PR 改变了画面，CI 会报出差异像素数和最大偏差。

## 五、扩展方向

- **SSIM 指标**：比逐像素差更符合人眼感知
- **差异可视化**：输出 diff 图（红=偏差大）方便人工审查
- **多平台基准**：每个 OS 维护自己的 golden 集
