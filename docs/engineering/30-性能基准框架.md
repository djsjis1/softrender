# 30 · 性能基准框架

> 企业级库必须量化性能。本项目提供零依赖的内置基准框架（`core/benchmark.h`），支持 RAII 计时和多次迭代统计。

对主 Renderer 的整帧比较使用[固定场景基线](58-覆盖规则与性能基线.md)，它以 steady_clock 记录逐帧分布，并输出图像哈希。下面的 Bench 是旧的局部实验工具，聚合平均值不能当作整帧分位数。

## 一、用法

```cpp
#include "core/benchmark.h"

// RAII 方式
{
    sr::Timer t("rasterize_100_triangles");
    for (int i = 0; i < 100; ++i) rasterize(...);
}

// 多次迭代
sr::benchRun("barycentric_1M", [&]() {
    volatile auto bc = barycentric(v0, v1, v2, p);
}, 1000000);

// 打印报告
sr::Bench::instance().report();
```

## 二、输出格式

```
===== Benchmark Results =====
Name                                         Avg(us)    Min(us)    Max(us)    Iters
----                                         -------    -------    -------    -----
rasterize_100_triangles                        45.20      42.10      51.30        1
barycentric_1M                                  0.01       0.01       0.02  1000000
=============================
```

## 三、设计要点

- **预热**：`benchRun` 先跑一次排除冷启动
- **微秒精度**：`std::chrono::high_resolution_clock`
- **聚合**：同名多次 record 自动累加
- **零开销**：不使用时不产生任何代码

## 四、对应代码

| 概念 | 代码 |
|---|---|
| RAII 计时器 | `core/benchmark.h`：`sr::Timer` |
| 多次迭代 | `sr::benchRun` |
| 结果聚合 | `sr::Bench::instance()` |
| 便捷宏 | `SR_BENCH(name, code)` |
