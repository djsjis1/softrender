# 26 · 内存池分配器

> 渲染器每帧产生大量临时对象（顶点缓冲、片元队列、插值中间值）。`new/delete` 的系统调用开销和碎片化在热路径上不可接受。线性内存池（Arena）用 O(1) 指针移动替代 malloc，帧末一次性 reset。

## 一、原理

预分配一大块内存（如 4MB），维护一个 `current` 指针。分配时：

1. 对齐 `current` 到 16 字节边界（SIMD 友好）
2. 返回 `current`，然后 `current += size`

释放时：`current = base`（O(1)，整块回收）。

## 二、适用场景

- 每帧生命周期相同的临时数据（光栅化中间缓冲、排序数组）
- 不需要单独释放的批量对象

**不适用**：跨帧存活的资源（纹理、网格）——这些用 RAII + std::allocator。

## 三、线程安全

每线程一个 Arena（`thread_local`），无锁。帧末各线程各自 reset。

## 四、对应代码

| 概念 | 代码 |
|---|---|
| Arena 类 | `core/arena.h`：`sr::ArenaAllocator` |
| 帧分配器 | `sr::frameArena()`（thread_local 单例） |
| 模板分配 | `arena.allocArray<T>(count)` |
| 帧末重置 | `arena.reset()` |

## 五、使用示例

```cpp
auto& arena = sr::frameArena();
float* tempZ = arena.allocArray<float>(W * H);
// ... 使用 tempZ ...
// 帧末自动 reset，无需手动 free
```

## 六、性能对比

| 分配方式 | 10000 次 64B 分配 | 碎片 |
|---|---|---|
| malloc/free | ~50μs | 有 |
| Arena alloc | ~2μs | 无 |
| Arena reset | O(1) | — |
