## 六、设计原则

1. **渲染器本体零依赖**：`src/` 默认只用 **C++23** 标准库（`vec.h` 用 `requires` 约束子句）；
   spdlog / SSE2 经条件编译隔离
2. **开源优先**：外围功能用成熟开源库（stb/tinygltf/EnTT/spdlog/gtest）
3. **header-only 为主**：减少编译单元，方便集成
4. **条件编译隔离**：spdlog/Win32 通过宏开关，不影响核心
5. **每阶段可独立编译运行**：stage1-12 + demo 各自独立
6. **测试驱动**：每次修改后 **97** 个测试全过才提交

> ⚠️ 原则 1 存在一处已知例外：`scene/gltf_loader.h` 与 `scene/animation_player.h`
> 在公共头中 include `tiny_gltf.h`，属于**有意的接口泄露**（需直接访问
> `tinygltf::Model` 的动画数据）。详见 `docs/architecture.md` §3。
