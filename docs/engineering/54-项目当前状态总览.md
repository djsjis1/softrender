# 54 · 项目当前状态总览

为避免 README、任务页和本章各自保存一份互相矛盾的数字，当前数据集中维护在[项目上下文](../project_context.md)。本章只说明如何理解这些状态。

## 功能存在与集成完成的区别

- 主 `Renderer` 串联顶点着色、六面裁剪、透视除法、深度测试和片元着色；discard 同时保留原颜色和深度。
- MSAA、PBR、SSAO、IBL、后处理和分条并行主要通过各自模块和示例展示，并非单个统一渲染入口的所有开关。
- 中心/子样本覆盖已统一到共享整数 top-left 规则；MSAA 示例只写逐样本深度测试通过的颜色，完整主 Renderer 仍是单样本管线。
- `rasterizer_fast.h` 的 SSE2 路径仍与主 Renderer 分离。不能把其局部基准性能当作主渲染管线性能。
- glTF/动画使用共享 accessor 校验，CubicSpline 已实现；sparse、压缩扩展、完整层级与通用 skin 导入仍不支持，不能视为完整 glTF 一致性。

## 验证层次

| 检查 | 证明什么 | 不证明什么 |
| --- | --- | --- |
| GoogleTest | 数学、缓冲、分配器等局部契约 | 所有模型和场景都正确 |
| 三张像素基准 | 对应确定性场景的联合渲染结果 | 未覆盖材质、MSAA 或动画的正确性 |
| 下游消费工程 | 包含、链接、版本、线程依赖和安装迁移可用 | 任意工具链或任意父工程目标组合兼容 |
| Debug ASAN | 已运行路径的内存错误检查 | 数据竞争、所有未定义行为或未运行路径 |
| CI 配置 | 定义了跨平台检查流程 | 未运行的远端作业已经通过 |
