## 四、构建与使用

```bash
# 配置 + 编译
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release

# 运行测试
ctest --test-dir build --output-on-failure

# 运行 demo
./build/bin/Release/demo_stars          # 群星闪耀 1920x1080
./build/bin/Release/demo_gltf           # glTF 加载 + Profiler

./build/bin/Release/stage8_realtime     # 实时窗口（Win32）
```

## 六、设计原则

1. **渲染器本体零依赖**：`src/` 纯 C++17 标准库
2. **开源优先**：外围功能用成熟开源库（stb/tinygltf/EnTT/spdlog/gtest）
3. **header-only 为主**：减少编译单元，方便集成
4. **条件编译隔离**：spdlog/Win32 通过宏开关，不影响核心
5. **每阶段可独立编译运行**：stage1-12 + demo 各自独立
6. **测试驱动**：每次修改后 62 测试全过才提交
