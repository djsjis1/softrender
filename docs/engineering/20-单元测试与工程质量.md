# 20 · 单元测试与工程质量

> 企业级库的标志之一：核心算法有自动化测试保护，重构不怕回归。本项目用 Google Test 覆盖 218 个用例 / 52 个套件，外加 3 个像素回归场景和下游消费工程验证。

## 一、测试框架

使用 Google Test（源码在 `third/googletest-main`），通过 CMake `add_subdirectory` 集成，零安装。

```bash
cmake --build build --config Release --target unit_tests
.\build\bin\Release\unit_tests.exe                              # 单进程跑全部单元测试
ctest --test-dir build -C Release -L "fast|regression"          # 单测 + 像素回归
ctest --test-dir build -C Release --parallel 4 -LE fast         # 完整 ctest（含下游消费工程）
```

## 三、CI 集成

在 GitHub Actions 中（三平台：Windows / Ubuntu / macOS）：

```yaml
- cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
- cmake --build build --config Release --parallel
- ctest --test-dir build -C Release -L "fast|regression" --output-on-failure
```

任何 PR 合并前必须全绿。像素回归使用编译期注入的绝对路径，ctest 工作目录不影响结果。
