# 20 · 单元测试与工程质量

> 企业级库的标志之一：核心算法有自动化测试保护，重构不怕回归。本项目用 Google Test 覆盖向量、矩阵、变换、重心坐标、裁剪、深度缓冲、纹理、网格、渲染队列共 35 个测试用例。

## 一、测试框架

使用 Google Test（源码在 `third/googletest-main`），通过 CMake `add_subdirectory` 集成，零安装。

```bash
cmake --build build --target unit_tests
ctest --test-dir build          # 或直接用 ctest 跑
./build/bin/Release/unit_tests  # 或直接运行
```

## 二、测试覆盖

| 测试套件 | 用例数 | 覆盖内容 |
|---|---|---|
| Vec | 7 | dot, cross, normalize, cross2, 加减乘 |
| Mat4 | 6 | identity, translate, inverse, rotateY |
| Transform | 3 | perspective w=-z, lookAt, ortho |
| Barycentric | 4 | 顶点/重心/外部/和为1 |
| Clip | 3 | 全内/全外/部分裁 |
| DepthBuffer | 2 | 近者胜/越界 |
| Texture | 3 | mipmap 生成/双线性均匀/最近邻 |
| Mesh | 4 | 立方体面数/球法线/平面网格/切线 |
| RenderQueue | 3 | 不透明排序/透明排序/层优先级 |

## 三、CI 集成建议

在 GitHub Actions / GitLab CI 中：

```yaml
- cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
- cmake --build build
- ctest --test-dir build --output-on-failure
```

任何 PR 合并前必须全绿。

## 四、扩展测试的方向

- **像素级回归测试**：渲染固定场景，对比输出 PNG 的哈希值。
- **性能基准**：用 `google-benchmark` 测量光栅化/着色器耗时。
- **模糊测试**：随机生成三角形/矩阵，验证不崩溃、不 NaN。
