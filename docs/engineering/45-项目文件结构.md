# 45 · 项目文件结构

> 完整目录树，标注每个文件/目录的职责。

```
softrender/
├── CMakeLists.txt              主构建脚本
├── .github/workflows/ci.yml    GitHub Actions CI（三平台）
├── cmake/
│   ├── version.cmake           版本号定义
│   ├── version.h.in            版本头模板
│   ├── install.cmake           安装/导出规则
│   └── SoftRendererConfig.cmake.in  find_package 配置
├── src/                        ★ 核心算法 + 场景加载（部分模块依赖第三方）
│   ├── math/
│   │   ├── vec.h               Vec2/3/4, dot, cross, cross2
│   │   ├── mat3.h              3x3 矩阵, 2D 仿射变换
│   │   ├── mat4.h              4x4 矩阵, 平移/旋转/缩放/求逆
│   │   ├── transform.h         lookAt, perspective, ortho, viewport
│   │   ├── transform2d.h       ortho2D, viewport2D（返回 Mat3）
│   │   ├── quat.h              四元数, SLERP, NLERP
│   │   └── rect.h              Rect2<T>, 裁剪与合并
│   ├── core/
│   │   ├── color.h             RGBA 颜色
│   │   ├── framebuffer.h       8位帧缓冲
│   │   ├── float_framebuffer.h 浮点帧缓冲（HDR）
│   │   ├── depthbuffer.h       深度缓冲
│   │   ├── msaa_framebuffer.h  MSAA 多样本缓冲
│   │   ├── tga.h               TGA 读写（保留，兼容旧代码）
│   │   ├── image_write.h       通用图像写出（stb_image_write）
│   │   ├── blend.h             Alpha 混合模式
│   │   ├── log.h               日志接口（条件编译 spdlog/内置）
│   │   ├── benchmark.h         性能基准框架
│   │   ├── arena.h             线性内存池
│   │   ├── resource_manager.h  资源管理器（引用计数+缓存）
│   │   ├── command_buffer.h    命令缓冲 + 线程池
│   │   ├── gbuffer.h           延迟渲染 G-Buffer
│   │   ├── ssao.h              屏幕空间环境光遮蔽
│   │   ├── fxaa.h              FXAA 后处理抗锯齿
│   │   ├── post_effects.h      DOF/运动模糊/暗角/色差
│   │   ├── profiler.h          Chrome Tracing 性能分析
│   │   └── namespace.h         命名空间迁移辅助宏
│   ├── raster/
│   │   ├── line.h              Bresenham 画线
│   │   ├── coverage.h          确定性子像素与 top-left 覆盖
│   │   ├── msaa_renderer.h     常量颜色的 1/4 样本渲染
│   │   ├── triangle.h          边函数+重心坐标三角形填充
│   │   ├── rasterizer_fast.h   增量式边函数+SSE2 并行（实验性）
│   │   ├── clip.h              6面视锥裁剪
│   │   ├── renderer.h          3D 可编程管线 Renderer
│   │   ├── shape2d.h           2D 图元（sr2d 命名空间）
│   │   ├── blit2d.h            2D 图像合成与 blit
│   │   └── renderer2d.h        2D 立即模式渲染器
│   ├── scene/
│   │   ├── mesh.h              网格+程序化生成+切线计算
│   │   ├── texture.h           纹理采样+mipmap+三线性
│   │   ├── image_loader.h      通用图像加载（stb_image）
│   │   ├── obj_loader.h        OBJ 加载（tinyobjloader）
│   │   ├── gltf_accessor.h     受校验的非拥有分量视图
│   │   ├── gltf_mesh.h         primitive 数据校验与转换
│   │   ├── gltf_loader.h       glTF 加载（tinygltf）
│   │   ├── gltf_loader_impl.cpp tinygltf 实现单元
│   │   ├── gltf_types.h        glTF PBR 材质类型
│   │   ├── camera.h            FPS 相机 + Camera2D
│   │   ├── cubemap.h           Cubemap+IBL
│   │   ├── skeleton.h          骨骼动画+蒙皮
│   │   ├── animation_player.h  动画采样与插值
│   │   ├── components.h        ECS 组件定义（sr 命名空间）
│   │   ├── render_queue.h      渲染队列+透明排序
│   │   └── particle_system.h   粒子系统
│   ├── shader/
│   │   ├── shader.h            Shader 基类+Varyings
│   │   ├── shaders.h           Flat/Gouraud/Phong
│   │   ├── pbr_shader.h        Cook-Torrance PBR
│   │   └── advanced_shaders.h  阴影+法线贴图
│   └── test/
│       └── pixel_regression.h  像素级回归测试
├── platform/
│   └── win32_window.h          Win32 GDI 窗口后端
├── benchmarks/                可选主渲染器固定场景基线
├── examples/                   22 个阶段示例 + 综合演示
├── practice/                   练习程序（hello_2d）
├── tests/
│   ├── unit/
│   │   ├── test_core.cpp       既有核心测试（继续按模块拆分的入口）
│   │   ├── arena_test.cpp      分配器边界与跨帧复用
│   │   ├── renderer_test.cpp   discard 与深度提交
│   │   ├── gltf_test.cpp       accessor/网格/纹理输入边界
│   │   ├── animation_test.cpp  数值插值与失败原子性
│   │   ├── command_buffer_test.cpp  任务失败和生命周期
│   │   ├── coverage_test.cpp   共享边/裁剪与 MSAA 缺陷回归
│   │   └── coverage_math_test.cpp  定点覆盖/尾部/输入边界
│   ├── integration/
│   │   ├── render_regression_test.cpp  像素回归（3 场景）
│   │   ├── consumer/           真实下游 CMake 消费工程
│   │   └── run_consumer.cmake  源码/安装迁移验证
│   └── fixtures/
│       └── golden/             像素回归基准图（*.tga）
├── third/                      第三方库源码
│   ├── googletest-main/
│   ├── log/ (spdlog + mylog 封装)
│   ├── stb/ (stb_image.h + stb_image_write.h)
│   ├── entt/
│   ├── tinygltf/ (tiny_gltf.h + impl)
│   ├── nlohmann/ (json.hpp)
│   ├── tiny_obj_loader.h
│   └── tiny_obj_loader_impl.cpp
├── docs/                       学习文档、当前状态与维护记录
└── output/                     渲染输出
```
