# 03 · 光栅化：从线段到三角形

> 屏幕是一张离散的像素网格，而三角形是连续的几何。**光栅化（rasterization）** 就是回答"这个连续形状，该点亮哪些像素"的过程。本篇讲两件事：怎么画一条线（Bresenham），怎么填一个三角形（边函数 + 重心坐标）。后者是整条渲染管线的插值基石。

## 一、光栅化在管线里的位置

回顾 `01` 的全景图：顶点经过变换，最终落在屏幕坐标上。但屏幕不是连续的画布，而是 $W\times H$ 个方格（像素）。光栅化的任务，是把"顶点围成的三角形"翻译成"一组像素坐标 + 每个像素的插值属性"。

它是连接"几何世界"与"像素世界"的桥梁。在它之前，一切都是浮点坐标；在它之后，一切都是整数像素。

## 二、画线：Bresenham 算法

给定两个整数端点，要点亮哪些像素？最朴素的想法是 $y = kx + b$ 逐 $x$ 求 $y$，但它有两个毛病：浮点慢、斜率 $|k|>1$ 时逐 $x$ 采样会**断线**（$y$ 一步跨过不止一个像素）。

Bresenham 用两个技巧解决，代码见 `include/softrenderer/render/draw2d/shape2d.h` 的 `drawLine`：

**技巧 A：陡峭线转置。** 若 $|dy| > |dx|$（线更"竖"），就把 $x$ 和 $y$ 交换，当作"横线"来画，画完再换回来。这保证我们总是沿**较长的那根轴**逐像素前进，短轴每步最多挪一格——于是绝不断线。

**技巧 B：整数误差累积。** 不直接算斜率，而是维护一个整数误差 `error2`。沿长轴每走一格，误差累加 $2|dy|$；一旦超过 $dx$，就让短轴挪一格并扣掉 $2dx$。全程只有整数加减和比较，没有浮点、没有除法。

```
error2 = 0
for x in 长轴:
    点亮像素
    error2 += 2*|dy|
    if error2 > dx:
        短轴挪一格
        error2 -= 2*dx
```

> 为什么是 $2dy$ 和 $2dx$ 而不是 $dy/dx$？因为真实判据是"误差 $\frac{dy}{dx}$ 是否超过 $0.5$"，两边同乘 $2dx$ 消去分母，得到纯整数比较。这是把浮点判据整数化的标准手法。

`drawLineGradient` 是它的变体：沿线段用参数 $t$ 在两端颜色间 `lerp`，顺便让你预习"插值"——下一节三角形的重心插值，正是它在二维的推广。

## 三、为什么是三角形

整个实时渲染世界都建在三角形上，不是四边形、不是圆。原因有三：

1. **必共面**：三个点一定在同一平面，不会有"翘曲"的四边形那种歧义。
2. **必凸**：三角形没有凹角，判断内外、做插值都简单且唯一。
3. **插值有唯一解**：三角形内任意点能唯一表示成三顶点的加权平均（重心坐标），属性插值因此良定义。

任何多边形都能**三角剖分**成三角形（OBJ 加载器 `obj_loader.h` 里对四边形/n 边形做的"三角扇拆分"就是这步）。所以只要会画三角形，就会画一切。

## 四、边函数：判断点在不在三角形内

给定三角形三顶点 $v_0, v_1, v_2$ 和一个点 $p$，怎么判断 $p$ 在内部？用 `02` 讲过的 **2D 叉积**构造**边函数**：

$$E_{01}(p) = (v_1 - v_0) \times (p - v_0)$$

它的符号告诉你 $p$ 在有向边 $v_0\!\to\!v_1$ 的左侧（正）还是右侧（负）。对三条边各算一次：

$$E_{01}(p),\quad E_{12}(p),\quad E_{20}(p)$$

**若三者同号，则 $p$ 在三角形内部**（全正或全负取决于绕序）。这就是光栅化的核心判据，代码里体现在 `triangle.h` 的 `barycentric` 中——它把这三个边函数值进一步归一化成了重心坐标。

## 五、重心坐标：插值的万能钥匙

三角形内任意点 $p$ 可唯一写成三顶点的加权和：

$$p = \alpha\, v_0 + \beta\, v_1 + \gamma\, v_2, \qquad \alpha+\beta+\gamma = 1$$

$(\alpha, \beta, \gamma)$ 就是 $p$ 的**重心坐标**。它有绝妙的几何意义：每个分量等于 $p$ 与对边构成的**子三角形面积**占总面积的比例。而"有向面积"正是边函数值的一半，于是：

$$\alpha = \frac{E_{12}(p)}{E},\quad \beta = \frac{E_{20}(p)}{E},\quad \gamma = \frac{E_{01}(p)}{E}$$

其中 $E$ 是整个三角形的 $2$ 倍有向面积。`barycentric` 函数正是这么算的，并在 $E\approx 0$（退化三角形）时返回负值标记。

**点在内部 $\iff \alpha, \beta, \gamma$ 全部 $\ge 0$。** 这比"三个边函数同号"更直接，还顺带给出了插值权重。

### 属性插值：重心坐标的真正威力

重心坐标一旦有了，**任何**顶点属性都能平滑插值到三角形内部：

$$\text{attr}(p) = \alpha\,\text{attr}_0 + \beta\,\text{attr}_1 + \gamma\,\text{attr}_2$$

颜色、深度、纹理坐标、法线，无一例外。`stage04_triangle.cpp` 里那个 RGB 大三角形，就是把三顶点设成纯红/纯绿/纯蓝，于是每个像素的颜色恰好等于它的重心坐标——**那张图本身就是重心坐标的可视化**。

> 这是 GPU 里 varying 变量插值的本质。光栅化器对每个像素算出重心坐标，再对所有属性做这个加权平均。记住这个公式，后面纹理（`06`）、光照（`07`）全是它的特例。

## 六、包围盒与像素中心采样

逐屏幕像素都算重心坐标太浪费。`fillTriangle` 先求三顶点的 **包围盒**（min/max 的 x、y），夹取到屏幕范围内，只遍历这个小矩形。绝大多数三角形只占屏幕一小块，这一下就把循环量从 $W\times H$ 砍到三角形面积量级。

遍历时的采样点取**像素中心** $(x+0.5, y+0.5)$ 而非整数角点。这是约定（见 `01`），它让"像素是否被覆盖"的判定更稳定，也减少相邻三角形边界的缝隙或重叠。

## 八、动手实验

1. **看断线**：临时把 `drawLine` 里"技巧 A"的转置 `if (steep) swap` 注释掉，画一条接近竖直的线，会看到明显的断点。理解转置为何必要。
2. **重心坐标可视化**：`stage2` 的 RGB 三角形里，红角对应 $\alpha=1$。在 `fillTriangleGradient` 里加一行：当某像素 $\alpha>0.9$ 时画成白色。你会看到红角附近出现一个白色小三角——那就是"$\alpha$ 接近 1"的区域。
3. **退化三角形**：构造三顶点共线的三角形喂给 `barycentric`，看它返回 `{-1,-1,-1}`。理解为什么光栅化要特判退化（面积为 0，除法会爆）。

## 九、小结

- 光栅化 = 连续几何 → 离散像素。
- **Bresenham** 用"转置陡峭线 + 整数误差"画出不断线的线段。
- 渲染只用**三角形**：共面、凸、插值唯一；多边形靠三角剖分。
- **边函数**（2D 叉积）判断点在边的哪一侧，三者同号即在内部。
- **重心坐标** = 面积比，是属性插值的万能公式 $\text{attr}=\alpha a_0+\beta a_1+\gamma a_2$。
- 包围盒 + 像素中心采样，是效率与正确性的两个实用细节。

线会画了、三角形会填了，但顶点还是"手填的 2D 坐标"。下一篇让它们真正在 3D 空间里动起来——**变换与投影**。

## 十、零基础补充：边函数到底怎么判断内外

很多教程只说"三个边函数同号 = 在内部"，但不说**为什么**。这里用图景解释。

### Step 1：一条边把平面切成两半

边 `v0 → v1` 是一根有向线段。2D 叉积 `cross2(v1−v0, p−v0)` 告诉我们 `p` 在这条边的**左侧**（正）还是**右侧**（负）。

```
   v0 ———→ v1
  左侧(+)     右侧(−)
```

### Step 2：逆时针三角形的性质

三角形三个顶点 v0,v1,v2 是**逆时针**排列的。从每条边看，三角形的**内部都在边的左侧**。

所以对三条边各算一次边函数，只要 p 对每条边都在左侧（全正），它就在三角形内部。这就是"三者同号"的几何本质。

### Step 3：用三角形自己验证

取三角形 (0,0), (4,0), (0,3)。点 p = (1,1) 在内部。

```cpp
// 边 0: (0,0)→(4,0)
float e0 = cross2((4,0), (1,1)) = 4·1 − 0·1 = 4  > 0 ✓
// 边 1: (4,0)→(0,3)
float e1 = cross2((-4,3), (1−4,1−0)) = cross2((-4,3), (-3,1)) = -4·1 − 3·(-3) = -4+9 = 5 > 0 ✓
// 边 2: (0,3)→(0,0)
float e2 = cross2((0,-3), (1,1−3)) = cross2((0,-3), (1,-2)) = 0·(-2) − (-3)·1 = 3 > 0 ✓
```

三个全正 → p 在内部。

### Step 4：用代码验证

在 `triangle.h` 找到 `barycentric` 函数，断点看它返回的 α,β,γ。全非负 = 内部。

### 重心坐标的面积含义（为什么 α+β+γ=1）

α = p 与 v1,v2 围成的**子三角形面积** / 整个三角形面积。同理 β 对应 v2,v0，γ 对应 v0,v1。

三个子面积加起来恰好等于总面积，所以 α+β+γ = 1。这就是重心坐标的几何意义——也是为什么它能用来做"加权平均"：内部点的 α,β,γ 正是三顶点对该点的"贡献比例"。

### 增量式优化：为什么从 3 次叉积变成 3 次加法

边函数对 x,y 是**线性**的：E(x+1, y) = E(x,y) + 常数。

所以只需在包围盒左上角算一次 E 的初始值，之后逐像素只加常量——把每像素 6 次乘法+6 次减法变成 3 次加法。这就是 `rasterizer_fast.h` 和 `renderer.h` 增量式边函数的原理（详见 `docs/advanced/22`）。
