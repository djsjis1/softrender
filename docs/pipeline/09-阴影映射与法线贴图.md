# 09 · 阴影映射与法线贴图

> 给画好的场景投下阴影、给平坦的表面加上假凹凸——两项"让画面瞬间高级"的技术。本篇讲清楚：Shadow Mapping 的两趟渲染原理、PCF 软化边缘、TBN 切线空间如何让法线贴图工作。

## 一、Shadow Mapping：两趟渲染投阴影

### 直觉

太阳照着你，你的影子投在地上。从太阳的位置看，影子区域是被你挡住、太阳"看不到"的地方。

**Shadow Mapping 的核心思路**：先从光源位置渲染一张深度图（shadow map），记录光源"看到"的最近深度。然后从相机渲染时，把每个片元换算到光源空间，比较它的深度——如果比 shadow map 里存的深，说明被遮挡，该片元在阴影中。

### 两趟 Pass

**Pass 1（阴影图）**：从光源视角渲染场景，不关心颜色，只记录深度到一张 1024×1024 的深度缓冲。

```cpp
// 光源的 MVP（正交投影，因为平行光没有透视）
Mat4 lightVP = lightProj * lightView;
DepthShader ds;
ds.mvp = lightVP * model;
renderer.drawMesh(shadowDummy, mesh, ds);
// 取 shadowRenderer.depth() 作为 shadow map
```

**Pass 2（主渲染）**：从相机视角正常渲染。每个片元换算到光源 NDC 空间，采样 shadow map 比较深度：

```cpp
// 片元的世界坐标 → 光源裁剪空间 → NDC → shadow map UV
Vec4f lightClip = lightVP * Vec4f(worldPos, 1.0f);
Vec3f lightNDC = {lightClip.x/lightClip.w, lightClip.y/lightClip.w, lightClip.z/lightClip.w};
float shadowDepth = lightNDC.z * 0.5f + 0.5f; // 转换到 [0,1]
float storedDepth = shadowMap->get(px, py);
bool inShadow = (shadowDepth - bias > storedDepth);
```

### PCF：软化阴影边缘

单次采样会产生硬锯齿边缘。**Percentage Closer Filtering**：在 shadow map 上采样 3×3 = 9 个点，统计有多少个点的深度比当前片元浅——比例就是阴影的"柔和度"。

```cpp
float lit = 0;
for (int dy = -1; dy <= 1; ++dy)
    for (int dx = -1; dx <= 1; ++dx) {
        float stored = shadowMap->get(px+dx, py+dy);
        if (shadowDepth - bias <= stored) lit++;
    }
float shadowFactor = lit / 9.0f; // 0=全阴影, 1=全亮
```

### 阴影偏移 bias

不加深度的微小偏移会出"自阴影"（shadow acne）——表面把自己投了阴影。原因：shadow map 的像素精度有限，平坦表面的相邻像素可能深度差极小。

```cpp
float bias = max(0.0025f, 0.01f * (1.0f - dot(N, L))); // 斜率自适应
```

## 二、法线贴图：平坦表面上的假凹凸

### 直觉

给一面墙贴上一张凹凸纹理，光打上去时亮暗变化像真的有凹凸。但三角形数量不变——只是每个像素的"着色法线"被修改了。

### 切线空间（TBN）

法线贴图存的是**切线空间**的法线（相对于表面的局部坐标系）。编码为 RGB：

```
平坦区域法线 = (0, 0, 1)  → 编码为 (128, 128, 255) 淡蓝紫色
```

要把它转到世界空间用于光照，需要 **TBN 矩阵**：

- **T**（Tangent）：沿纹理 U 增大方向的 3D 向量
- **B**（Bitangent）：沿纹理 V 增大方向的 3D 向量（= cross(N, T)）
- **N**（Normal）：原始顶点法线

```cpp
// 解码切线空间法线
Vec3f tsNormal{texColor.r*2-1, texColor.g*2-1, texColor.b*2-1};
// 转到世界空间
Vec3f wsNormal = T * tsNormal.x + B * tsNormal.y + N * tsNormal.z;
```

### 切线计算

从三角形三个顶点的位置差和 UV 差解线性方程组：

```
e1 = v1 - v0,  deltaUV1 = uv1 - uv0
e2 = v2 - v0,  deltaUV2 = uv2 - uv0
T = (deltaUV2.y * e1 - deltaUV1.y * e2) / (deltaUV1.x * deltaUV2.y - deltaUV2.x * deltaUV1.y)
```

代码在 `mesh.h` 的 `computeTangents()`。

## 四、动手实验

1. **关掉阴影**：在 `stage10_shadow_live` 中按 `B` 键——地面上的物体阴影消失。
2. **关掉法线贴图**：按 `N` 键——地面和球体的凹凸细节消失，表面变平滑。
3. **改 PCF 采样范围**：在 `computeShadow` 中把 3×3 改 5×5——阴影边缘更软、更模糊。
4. **改 bias**：把 `shadowBias` 从 0.0025 改成 0——出现大量自阴影斑纹（shadow acne）。
