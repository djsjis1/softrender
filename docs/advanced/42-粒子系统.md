# 42 · 粒子系统

> Billboard 粒子 + 发射器。每个粒子是面向相机的四边形，用加法混合渲染。发射器控制生成速率、速度、生命周期。

## 一、核心概念

| 概念 | 说明 |
|---|---|
| Particle | 位置、速度、颜色、尺寸、生命值 |
| EmitterConfig | 发射方向、扩散角、速率、重力、颜色渐变 |
| ParticleSystem | 管理粒子池，每帧 update(dt) |

## 二、生命周期

1. **发射**：按 rate 每秒生成 N 个粒子，随机方向+速度
2. **更新**：施加重力、移动位置、颜色插值、尺寸缩小
3. **死亡**：life <= 0 时回收槽位
4. **渲染**：获取存活粒子列表，画 billboard 四边形

## 三、用法

```cpp
EmitterConfig cfg;
cfg.position = {0, 0, 0};
cfg.direction = {0, 1, 0};
cfg.rate = 100;
cfg.colorStart = Color(255, 200, 50);
cfg.colorEnd = Color(255, 50, 0, 0);
ParticleSystem ps(cfg);

// 每帧
ps.update(dt);
auto alive = ps.getAlive();
for (auto* p : alive) { /* 画 billboard */ }
```
