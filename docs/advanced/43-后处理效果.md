# 43 · 后处理效果

> 渲染完成后的全屏像素操作：DOF 景深、运动模糊、暗角、色差。

## 一、效果列表

| 效果 | 函数 | 原理 |
|---|---|---|
| DOF 景深 | `postprocess::depthOfField` | 根据深度计算 CoC，box blur |
| 径向运动模糊 | `postprocess::radialMotionBlur` | 沿屏幕径向方向采样 |
| 暗角 | `postprocess::vignette` | 边缘亮度衰减 |
| 色差 | `postprocess::chromaticAberration` | R/B 通道径向偏移 |

## 二、DOF 原理

Circle of Confusion (CoC) = |depth - focusDist| / focusRange

CoC 越大，模糊半径越大。焦点平面 CoC=0，完全清晰。

## 三、用法

```cpp
#include "core/post_effects.h"

// DOF
postprocess::depthOfField(colorBuf, depthBuf, W, H,
    /*focusDist=*/ 5.0f, /*focusRange=*/ 3.0f, /*maxBlur=*/ 8,
    outBuf);

// 暗角
postprocess::vignette(outBuf, 0.4f);

// 色差
postprocess::chromaticAberration(outBuf, W, H, 3.0f, finalBuf);
```
