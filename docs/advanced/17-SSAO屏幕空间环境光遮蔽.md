# 17 · SSAO 屏幕空间环境光遮蔽

> 全局光照太贵，环境光太假。SSAO 是两者的折中：只用深度+法线缓冲，在屏幕空间估算每个像素被周围几何遮挡的程度，给缝隙和接触面加上柔和暗影。

## 一、问题

经典的环境光是一个常数——背对光源的死角也收到同样亮度的环境光，画面失去立体感。真正的全局光照会计算光线在场景中多次反弹后的结果，但计算量巨大。

**SSAO 的思想**：如果重建场景的局部 3D 几何（从深度缓冲），就能估算每个点周围有多少几何体遮挡了漫反射半球——遮挡越多就越暗。

## 二、原理

对每个像素，在视图空间法线半球内撒 N 个随机采样点：

1. 把每个采样点投影回屏幕空间查深度
2. 如果采样点的深度 > 该处实际深度，说明这个采样点被更近的物体遮挡
3. 被遮挡的采样点比例 = AO 因子（0=全遮挡暗，1=全亮）

## 三、关键组件

| 组件 | 做什么 |
|---|---|
| **采样核** | 半球内 16~64 个随机方向，加速分布（近密远疏） |
| **噪声纹理** | 4×4 随机旋转向量，每像素用噪声旋转采样核——16 个样本转出几百个方向的花纹 |
| **TBN** | 把切线空间采样核转到视图空间 |
| **Range Check** | 只计距离在半径内的遮挡，避免远处物体误判 |
| **Blur** | AO 图有噪声，用 4×4 box blur 降噪后再合成 |

## 四、代码入口

```cpp
#include "core/ssao.h"

SSAO ssao;
ssao.compute(viewPositions, viewNormals, depthBuffer, W, H, viewProj, aoMap);
SSAO::blur(aoMap, W, H, smoothAo, 2); // 降噪

// 合成：ambient *= aoFactor，在片元着色器中
```

## 五、动手实验

1. 把 `sampleCount` 从 16 改到 4——噪点暴增但快很多（体会样本数 vs 质量的权衡）
2. 把 `radius` 翻倍——AO 影响范围变大，接触阴影更宽
3. 去掉 blur pass——原始 SSAO 有明显的黑白噪点模式，理解为什么降噪是必须的

## 六、局限性

- **屏幕空间**：看不到被遮挡的几何（如物体背后的墙），可能产生错误的 AO
- **低分辨率噪声**：需要降噪，否则颗粒感重
- **性能**：每像素 16-64 次随机采样 + 投影 + 深度比较
