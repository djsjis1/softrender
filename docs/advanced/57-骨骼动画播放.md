# 57 · 骨骼动画播放

动画采用 channels + samplers：channel 指定节点与 TRS 分量，sampler 指向时间和数值 accessor。
`sampleChannel` 支持 Linear、Step、CubicSpline，失败返回 false 且不改变输出。
`sampleAnimation` 将成功结果合并到各节点 bind pose，并设置 hasTranslation/hasRotation/hasScale。

## 解析一次，反复采样

动画结果只保留 accessor 编号，必须同时保存对应的 tinygltf::Model。下面的 model 与转换结果来自同一次解析，
不能用另一个文件或重新排列过 accessor 的模型替换。

```cpp
#include "scene/gltf_loader.h"

tinygltf::Model model;
tinygltf::TinyGLTF loader;
std::string error, warning;
if (!loader.LoadBinaryFromFile(&model, &error, &warning, "animated.glb")) {
    report(error);
    return;
}
auto result = sr::gltf::convertModel(model);
if (!result.success || result.animations.empty()) return;

auto samples = sampleAnimation(model, result.animations.front(), elapsedSeconds);
for (const auto& sample : samples) {
    Mat4 local = animSampleToMatrix(sample);
    // 节点层级、全局关节变换和蒙皮权重由调用方继续求值。
}
```

`AnimSample::nodeIndex` 默认 -1，采样失败不会误合并到随机节点。只有实际应用的 channel 才设置对应标志。
无效 channel 在 sampleAnimation 中被忽略，保留原 bind pose；需要逐 channel 错误观测时使用 sampleChannel 的 bool。
带静态 matrix 的节点仍需由场景求值器处理，本函数的 bind pose 是 TRS。

## 插值和验证

| 模式 | 行为 |
| --- | --- |
| LINEAR | 位移/缩放线性插值，旋转先归一化再做最短弧 SLERP |
| STEP | 取当前区间左端关键帧；恰好命中下一个时间戳时取新帧 |
| CUBICSPLINE | 每帧读取入切线、数值、出切线三元组，Hermite 切线乘以时间间隔，旋转结果归一化 |

时间超出有效区间时钳制到首/末帧，不自动循环。输入必须是非负、有限、严格递增的 FLOAT SCALAR；
输出必须匹配路径与帧数，三次样条输出数量是时间戳数量的三倍。
平移/缩放使用 FLOAT VEC3，旋转使用 FLOAT 或归一化整数 VEC4。动画 accessor 必须紧密存放。
零四元数、非有限采样结果、错误下标和截断字节均返回失败。

当前每次采样校验完整时间序列，再读所需数值；不分配逐通道时间数组，也不缓存可变模型的裸地址。
大规模角色的下一步是显式拥有数据的预编译动画缓存，以避免重复 O(关键帧数) 校验；当前没有此性能优化的测量结论。

## 示例与限制

`examples/demo_skinning.cpp` 生成两关节测试模型并输出逐帧图像；逆绑定矩阵通过共享 AccessorView 读取，
按 glTF 列主序转换到内部行主序。此示例仍使用简化的关节绑定和局部变换，不是通用层级蒙皮导入器。
