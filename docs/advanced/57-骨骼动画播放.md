# 57 · 骨骼动画播放

> glTF 动画通过 channels + samplers 描述关键帧。本项目支持 Linear/Step 插值，旋转用四元数 SLERP。

## 一、glTF 动画结构

```
Animation
  ├── channels[]
  │     ├── target_node    → 哪个节点
  │     ├── target_path    → translation / rotation / scale
  │     └── sampler        → 指向 samplers[]
  └── samplers[]
        ├── input          → accessor（时间戳 float[]）
        ├── output         → accessor（关键帧值 vec3/vec4[]）
        └── interpolation  → LINEAR / STEP / CUBICSPLINE
```

## 二、播放流程

```cpp
// 1. 加载 glTF（含动画）
auto result = gltfloader::load("animated.glb");

// 2. 每帧采样
float time = elapsed; // 秒
auto samples = sampleAnimation(model, result.animations[0], time);

// 3. 构建节点变换
for (auto& s : samples) {
    Mat4 local = animSampleToMatrix(s);
    // 递归计算全局变换 = parent_global * local
}

// 4. 蒙皮渲染（如果有 skin）
// skinnedPos = Σ weight_j * globalJoint_j * inverseBind_j * bindPos
```

## 三、插值方式

| 方式 | 说明 | 本项目 |
|---|---|---|
| LINEAR | 线性插值（旋转用 SLERP） | ✅ |
| STEP | 阶跃（取前一帧） | ✅ |
| CUBICSPLINE | 三次样条 | 🔜 简化为 Linear |
