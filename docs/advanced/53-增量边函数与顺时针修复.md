# 53 · 增量边函数与顺时针修复

> 增量边函数将每像素 3 次叉积优化为 3 次加法，但必须正确处理顺时针三角形。

## 一、问题

增量边函数假设 `area2 > 0`（逆时针），内部像素边函数全 ≥ 0。当 `cullBackface = false` 时，顺时针三角形 `area2 < 0`，内部像素边函数全 ≤ 0，判定 `>= 0` 永远失败 → 三角形不渲染。

## 二、修复

```cpp
float sign = 1.0f;
if (area2 < 0) { sign = -1.0f; e0 = -e0; e1 = -e1; e2 = -e2; }

// 增量也乘 sign
float de0_dx = -(p1.y - p0.y) * sign;
// ...

// invArea 取绝对值
float invArea = 1.0f / std::abs(area2);
```

翻转后，无论顺逆时针，内部像素边函数统一 ≥ 0，判定逻辑不变。

## 三、验证

- `stage8_offline`（逆时针为主）：无回归 ✅
- `demo_pbr_material`（顺时针三角形 + cullBackface=false）：正确渲染 ✅
- 62 单元测试全过 ✅
