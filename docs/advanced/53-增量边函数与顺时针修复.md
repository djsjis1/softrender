# 53 · 增量边函数与绕序

旧实现曾假定面积为正，顺时针三角形会被错误丢弃。当前需分别理解覆盖与插值的符号归一化。

- Renderer 按原始屏幕面积执行可选背面剔除；关闭 cullBackface 后可绘制两种绕序。
- TriangleCoverage 对量化后几何归一化边方向，并应用 y 向上的 top-left 归属规则。
- 浮点插值边式乘面积符号，invArea 使用绝对面积的倒数；覆盖偏置不参与插值。
- 量化后退化、非有限或超过覆盖坐标范围的三角形不绘制。

边函数与属性权重是错位映射：边 01 对应顶点 2，边 12 对应顶点 0，边 20 对应顶点 1。
因此深度表达式是 `(e1*z0 + e2*z1 + e0*z2) * invArea`。

测试以互不相等的顶点深度验证权重，同时测试绕序反转、绘制顺序、共享边和裁剪后覆盖。
最新数量和运行环境集中维护在[项目上下文](../project_context.md)，本章不保留旧的用例计数。

代码入口：`include/softrenderer/render/raster/coverage.h`、`renderer.h`、`rasterizer_fast.h`。
完整规则见[增量式边函数与 SIMD 光栅化](22-增量式边函数与SIMD光栅化.md)。
