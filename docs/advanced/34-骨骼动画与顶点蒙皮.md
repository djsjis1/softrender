# 34 · 骨骼动画与顶点蒙皮

> 角色动画的核心：骨骼层级驱动网格变形。每个顶点绑定最多 4 根骨骼，每帧根据动画关键帧插值骨骼变换，加权混合得到蒙皮后的顶点位置。

## 一、数据结构

```
Skeleton
  └── Bone[]
        ├── name
        ├── parent (index)
        ├── localTransform (bind pose)
        └── inverseBindMatrix

VertexBoneWeights
  ├── boneIndices[4]
  └── weights[4]

Animation
  └── AnimationChannel[]
        ├── boneIndex
        └── Keyframe[] (time, translation, rotation, scale)
```

## 二、每帧流程

1. **采样动画**：对每个 channel，在当前时间二分查找相邻关键帧，线性插值得到局部变换
2. **计算全局变换**：从根到叶递归 `global[i] = global[parent] * local[i]`
3. **蒙皮矩阵**：`skin[i] = global[i] * inverseBindMatrix[i]`
4. **顶点蒙皮**：`skinnedPos = Σ weight_j * skin[bone_j] * bindPos`

## 三、线性混合蒙皮（LBS）

$$p' = \sum_{j=0}^{3} w_j \cdot M_j \cdot p$$

其中 $M_j$ 是第 $j$ 根骨骼的蒙皮矩阵，$w_j$ 是权重（$\sum w_j = 1$）。

法线同理，但用 `transformDir`（只旋转不平移）。

## 四、对应代码

| 概念 | 代码 |
|---|---|
| 骨骼 | `scene/skeleton.h`：`Bone`, `Skeleton` |
| 蒙皮权重 | `VertexBoneWeights` |
| 蒙皮变换 | `skinPosition`, `skinNormal` |
| 动画采样 | `sampleAnimation(channel, time)` |
| 关键帧→矩阵 | `makeTransform(keyframe)` |

## 五、进阶方向

- **四元数插值**（SLERP）：避免欧拉角万向节锁
- **对偶四元数蒙皮**（DQS）：解决 LBS 的"糖果纸"收缩
- **动画混合**：多动画按权重叠加（如走路+射击）
- **glTF 加载**：解析 glTF 的 skin/animation 节点
