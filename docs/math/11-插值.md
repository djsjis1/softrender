# 11 · 插值

> 渲染里几乎无处不在的操作——颜色渐变、动画过渡、顶点属性、重心坐标、透视校正。本质上都是"在两个东西之间按比例取中间值"。

## 一、线性插值 lerp

$$lerp(a, b, t) = a + (b - a) \cdot t, \quad t \in [0, 1]$$

直觉：从 a 出发，沿 a→b 方向走 t 比例。t=0 得 a，t=1 得 b，t=0.5 得中点。

代码：`lerp(a, b, t)` 在 `vec.h`，支持 Vec2/3/4 任意维度（通用模板）。

```cpp
Vec3f start{0, 0, 0}, end{10, 0, 0};
Vec3f mid = lerp(start, end, 0.5f);  // (5, 0, 0)
```

## 二、重心坐标：三角插值的三路版本

三角形内任意点 p 可以写成三顶点的**加权平均**：

$$p = \alpha \cdot v_0 + \beta \cdot v_1 + \gamma \cdot v_2, \quad \alpha + \beta + \gamma = 1$$

每个分量的几何意义：该顶点**对面的子三角形面积**占总面积的比例。

代码：`triangle.h` 的 `barycentric(v0, v1, v2, p)` 返回 `(α, β, γ)`。

```cpp
Vec3f bc = barycentric(v0, v1, v2, p);
// 属性插值：任何顶点属性都可用同样的 α,β,γ 加权
float z   = bc.x * z0   + bc.y * z1   + bc.z * z2;   // 深度
Vec2f uv  = bc.x * uv0  + bc.y * uv1  + bc.z * uv2;  // 纹理坐标
Vec3f n   = bc.x * n0   + bc.y * n1   + bc.z * n2;   // 法线
```

这是 GPU 里 `varying` 变量的本质——光栅化器算出重心坐标，对所有属性做加权平均。

## 三、透视校正插值：屏幕空间不能直接插 UV

**关键陷阱**：透视除法破坏了线性。屏幕空间直接插 UV 会扭曲（就像 PS1 时代的纹理抖动）。

正确做法：插 `u/w, v/w, 1/w`，再相除还原：

```cpp
// 错误（仿射）：屏幕空间直接插
float u = bc.x * uv0.x + bc.y * uv1.x + bc.z * uv2.x;

// 正确（透视校正）：插 u/w 再除 1/w
float iw = bc.x * (1/w0) + bc.y * (1/w1) + bc.z * (1/w2);
float uw = bc.x * (uv0.x/w0) + bc.y * (uv1.x/w0) + bc.z * (uv2.x/w2);
float u = uw / iw;
```

代码：`shader.h` 的 `interpolateVaryings` 用透视校正插值所有 Varyings 字段。

## 四、全部插值函数速查

| 函数 | 公式 | 用途 | 位置 |
|---|---|---|---|
| `lerp(a,b,t)` | `a + (b-a)·t` | 颜色过渡、动画关键帧、粒子衰减 | `vec.h` |
| `mix(a,b,t)` | 同 lerp | GLSL 别名 | `vec.h` |
| `barycentric` | α+β+γ=1 | 三角形内插值（深度/UV/法线） | `triangle.h` |
| `interpolateVaryings` | 透视校正 | 片元着色器的全部输入 | `shader.h` |
| `slerp(a,b,t)` | 球面线性 | 四元数旋转插值 | `quat.h` |
| `Color::lerp` | 逐通道 lerp | 逐顶点颜色插值 | `color.h` |

## 五、动手实验

在 `stage07_texture.cpp` 里把右半屏的透视校正插值改回仿射（`correct=false`）——你会看到棋盘格沿三角形对角线折断、扭曲。这就是"忘记透视校正"的视觉代价。
