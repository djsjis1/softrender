# 09 · 视口变换

> NDC `[-1,1]³` 是一块"规整的立方体"，和屏幕分辨率无关。视口变换负责把它"贴"到具体的像素网格上，同时把 z 映射到 `[0,1]` 喂给深度缓冲。

## 一、直觉

NDC 里，x 从左（-1）到右（+1），y 从下（-1）到上（+1），z 从远（+1）到近（-1）。

屏幕是 `W × H` 个像素，x 从 0 到 W，y 从 0 到 H。深度缓冲需要 `[0,1]` 的 z 值。

所以视口变换就是：**每个轴做一次"从 [-1,1] 映射到目标范围"的平移+缩放**。

## 二、公式推导

### x 轴：[-1,1] → [0, W)

```
x_screen = (x_ndc * 0.5 + 0.5) * W
```

验证：
- x_ndc = -1 → (-1×0.5+0.5)×W = 0×W = 0 ✓
- x_ndc = +1 → (+1×0.5+0.5)×W = 1×W = W ✓

### y 轴同理

```
y_screen = (y_ndc * 0.5 + 0.5) * H
```

### z 轴：[-1,1] → [0,1]

```
z_screen = z_ndc * 0.5 + 0.5
```

验证：
- z_ndc = -1（近平面）→ 0.5×(-1)+0.5 = 0（最近，深度缓冲最小值）
- z_ndc = +1（远平面）→ 0.5×1+0.5 = 1（最远）

### 写成矩阵

上面三个公式可以直接写成 4×4 矩阵：

```
| W/2    0    0   W/2 |   | x_ndc |   | x_screen |
|   0  H/2    0   H/2 | × | y_ndc | = | y_screen |
|   0    0  0.5  0.5  |   | z_ndc |   | z_screen |
|   0    0    0     1  |   | 1     |   | 1        |
```

代码：`transform::viewport(W, H)` 就是构造这个矩阵。

## 三、代码入口

```cpp
// transform.h
Mat4 vp = transform::viewport(800, 600);

// renderer.h 里用它把 NDC 坐标转到屏幕
Vec3f screen = vp.transformPoint(ndc);
// screen.x = 像素 x 坐标（浮点）
// screen.y = 像素 y 坐标（浮点）
// screen.z = 深度值 ∈ [0,1]
```

## 四、动手实验

在 `stage05_transform.cpp` 的 `project` lambda 里打印视口变换前后的值。把宽度从 800 改成 400——画面会压到左半屏。理解视口只负责"把立方体贴到像素格"，不改变透视。

## 五、常见错误

| 错误 | 后果 | 原因 |
|---|---|---|
| 忘记做视口变换 | 画面挤在 `[-1,1]²` 区域，屏幕大部分是黑的 | NDC 还没映射到像素 |
| 忘记乘 `viewport` 矩阵 | 深度值在 `[-1,1]` 而非 `[0,1]` | 深度缓冲约定不对 |
