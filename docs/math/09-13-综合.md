# 09 · 视口变换

NDC `[-1,1]³` → 屏幕像素。一次平移+缩放即可：

```cpp
x_screen = (x_ndc * 0.5 + 0.5) * width;
y_screen = (y_ndc * 0.5 + 0.5) * height;
z_screen = z_ndc * 0.5 + 0.5;  // 给深度缓冲用
```

代码：`transform::viewport(w, h)`，返回一个 Mat4。

# 10 · 四元数

**为什么不用欧拉角**：万向节锁（两个轴对齐时丢失自由度）。矩阵插值又会变形。

**四元数 = 旋转的正确工具**。骨骼动画的旋转插值全靠它。

| 操作 | 代码 |
|---|---|
| 构造 | `Quat::fromAxisAngle(axis, rad)` |
| 旋转向量 | `q.rotate(v)` |
| 转矩阵 | `q.toMat4()` |
| SLERP 插值 | `slerp(a, b, t)` |
| NLERP 插值 | `nlerp(a, b, t)` |

动手：在 `animation_player.h` 找 `slerp(q0, q1, alpha)`，把它换成 `nlerp`——动画速度略变，但看不出差异。

# 11 · 插值

| 函数 | 公式 | 用途 |
|---|---|---|
| `lerp(a,b,t)` | `a + (b-a)·t` | 颜色渐变、动画过渡、属性插值 |
| `mix(a,b,t)` | 同 lerp | GLSL 别名 |
| **重心坐标** | α+β+γ=1 | 三角形内任意点 = 三顶点的加权平均 |
| **透视校正** | 插 u/w 再除 1/w | 屏幕空间不能直接插 UV |

代码：`lerp` 在 `vec.h`、重心坐标在 `triangle.h` `barycentric`、透视校正在 `shader.h` `interpolateVaryings`。

# 12 · 反射与折射

**反射**：`reflect(I, N) = I - 2(N·I)·N`

几何意义：入射方向关于法线对称翻转。用于 IBL 环境反射、镜面。

**折射**（Snell 定律）：`η₁·sinθ₁ = η₂·sinθ₂`

`refract(I, N, η)` 实现。`η = 1/1.33` 是空气→水。

全反射（k < 0）时返回零向量——玻璃/水的掠射角效果。

# 13 · 速查表

| 你要做的事 | 用哪个函数 | 在哪个文件 |
|---|---|---|
| 两向量夹角/光照亮度 | `dot(a, b)` | `vec.h` |
| 三角形法线 | `cross(v1-v0, v2-v0).normalized()` | `vec.h` |
| 像素在三角形内？ | `cross2(e, p-v) >= 0` 三边同号 | `triangle.h` |
| 平移 | `Mat4::translate(x,y,z)` | `mat4.h` |
| 旋转 | `Mat4::rotateY(rad)` | `mat4.h` |
| 组合变换 | `proj * view * model` | `mat4.h` |
| 相机看向某点 | `lookAt(eye, target, up)` | `transform.h` |
| 透视矩阵 | `perspective(fov, aspect, n, f)` | `transform.h` |
| 视口映射 | `viewport(w, h)` | `transform.h` |
| 骨骼旋转插值 | `slerp(q0, q1, t)` | `quat.h` |
| 颜色/属性过渡 | `lerp(a, b, t)` | `vec.h` |
| 反射方向 | `reflect(I, N)` | `vec.h` |
| 折射方向 | `refract(I, N, eta)` | `vec.h` |
| clamp 到范围 | `clamp(v, lo, hi)` | `vec.h` |
| 包围盒 | `min(a,b) / max(a,b)` | `vec.h` |
| 两点距离 | `distance(a, b)` 或用 `distanceSq` 省开方 | `vec.h` |
