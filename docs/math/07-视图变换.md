# 07 · 视图变换（lookAt）

> 世界空间 → 相机空间。核心思想：与其"移动相机"，不如"把整个世界反向搬"。

## 一、直觉

相机在世界坐标 (3, 1, 2) 朝某个方向看。如果我们把整个世界做一个相反的变换——平移 (-3,-1,-2) 然后旋转——相机就回到原点朝 -Z 看了。这个合并的平移+旋转矩阵就是**视图矩阵**。

代码：`transform::lookAt(eye, target, up)`。

## 二、推导步骤

三个输入：

- `eye`：相机在世界空间的位置，比如 `(0, 0, 5)`
- `target`：相机在看谁，比如 `(0, 0, 0)`（看原点）
- `up`：哪个方向算"上"，通常是 `(0, 1, 0)`

**第一步**：算出相机的三个基向量（forward, right, up）

```cpp
Vec3f f = normalize(eye - target);   // 相机"背后"方向（看向 -Z）
Vec3f r = normalize(cross(up, f));   // 相机"右侧"方向
Vec3f u = cross(f, r);               // 相机"上方"方向
```

**第二步**：把基向量按**行**排成旋转矩阵（正交矩阵的逆 = 转置，所以按行排就是"世界→相机"的旋转）

**第三步**：补上 `-base · eye` 的平移（把相机位置挪回原点）

最终矩阵对应代码 `transform.h` 第 23-40 行。

## 三、口诀

**lookAt = 相机基向量按行排成旋转 + 添上 '-基·eye' 平移。**
