# 13 · 速查表

> 一页查所有：你要做某件事，用哪个函数、在哪、公式是什么。

## 一、向量运算

| 要做的事 | 代码 | 公式 | 文件 |
|---|---|---|---|
| 两向量夹角（光照亮度） | `dot(a, b)` | `Σ a[i]·b[i] = |a||b|cosθ` | `vec.h` |
| 三角形法线 | `cross(v1-v0, v2-v0).normalized()` | `a×b` | `vec.h` |
| 像素在三角形内？ | `cross2(e, p-v) >= 0` 三边同号 | `a.x·b.y − a.y·b.x` | `triangle.h` |
| 向量长度 | `v.length()` | `√(x²+y²+z²)` | `vec.h` |
| 单位化 | `v.normalized()` | `v / |v|` | `vec.h` |
| 两点距离 | `distance(a, b)` | `|b−a|` | `vec.h` |
| 省开方的距离 | `distanceSq(a, b)` | `|b−a|²` | `vec.h` |
| 线性插值 | `lerp(a, b, t)` | `a + (b−a)·t` | `vec.h` |
| 反射方向 | `reflect(I, N)` | `I − 2(N·I)N` | `vec.h` |
| 折射方向 | `refract(I, N, eta)` | Snell 定律 | `vec.h` |
| 逐分量钳制 | `clamp(v, lo, hi)` | `min(max(v[i], lo), hi)` | `vec.h` |
| 逐分量取小 | `min(a, b)` | `min(a[i], b[i])` | `vec.h` |
| 逐分量取大 | `max(a, b)` | `max(a[i], b[i])` | `vec.h` |
