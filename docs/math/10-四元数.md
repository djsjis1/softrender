# 10 · 四元数

> 欧拉角有万向节锁，矩阵插值会变形。四元数是旋转的正确工具——骨骼动画的旋转插值全靠它。

## 一、万向节锁：为什么欧拉角不行

欧拉角用 3 个数 (yaw, pitch, roll) 表示旋转。问题：当 pitch = 90° 时，yaw 和 roll 的转轴重合，丢失一个自由度——这就是万向节锁。

后果：相机转到头顶时突然"抽风"，动画的旋转插值不平滑。

**四元数用 4 个数 (x, y, z, w) 表示旋转，没有万向节锁。**

## 二、四元数是什么（直觉）

粗略理解：一个四元数 = "绕着某个轴转某个角度"。

$$
q = (\sin\frac{\theta}{2} \cdot axis,\; \cos\frac{\theta}{2})
$$

其中 `axis` 是旋转轴（单位向量），`θ` 是旋转角度。

代码：
```cpp
Quat q = Quat::fromAxisAngle(Vec3f{0, 1, 0}, 3.14f/2);
// 绕 Y 轴转 90 度
```

## 三、核心操作

| 操作 | 代码 | 说明 |
|---|---|---|
| 轴角→四元数 | `Quat::fromAxisAngle(axis, rad)` | 绕任意轴转 |
| 欧拉角→四元数 | `Quat::fromEuler(yaw, pitch, roll)` | 从 yaw/pitch/roll 构造 |
| 旋转向量 | `q.rotate(v)` | 用四元数旋转一个向量 |
| 转矩阵 | `q.toMat4()` | 转成矩阵，接入管线 |
| **SLERP** | `slerp(a, b, t)` | 球面线性插值——恒角速度，精确 |
| **NLERP** | `nlerp(a, b, t)` | 归一化线性插值——更快，非恒速 |

## 四、SLERP vs NLERP

```cpp
// SLERP：恒角速度，精确。动画关键帧用这个
Quat between = slerp(keyframeA, keyframeB, 0.5f); // 介于两者之间

// NLERP：只做 lerp + normalize，比 SLERP 快得多
// 视觉差异极小，游戏引擎常用
Quat fast = nlerp(keyframeA, keyframeB, 0.5f);
```

## 五、动手实验

1. 在 `animation_player.h` 把 `slerp(q0, q1, alpha)` 换成 `nlerp(q0, q1, alpha)`——动画速度略不均匀，但肉眼难辨。
2. 在测试 `TEST(Quat, SlerpEndpoints)` 中看 `slerp(a,b,0)` 是否等于 a，`slerp(a,b,1)` 是否等于 b。
3. 构造一个欧拉角 (45°, 90°, 30°)，转成四元数再转回矩阵，对比和 `rotateY * rotateX * rotateZ` 的结果是否一致。

## 六、注意事项

- **四元数归一化**：插值后的四元数长度不再为 1，必须 `normalized()` 再转矩阵。
- **单位四元数**：`(0,0,0,1)` 表示"不旋转"。
- **四元数不唯一**：q 和 -q 表示同一个旋转。SLERP 会自动取短弧（用 `dot` 判符号）。
