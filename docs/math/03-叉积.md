# 03 · 叉积

> 叉积是光栅化的灵魂——三角形填充、法线计算、背面剔除全部靠它。这篇讲清楚 3D 叉积（造法线）和 2D 叉积（判内外），以及它们背后统一的几何含义：**面积**。

## 一、直觉

### 3D 叉积：造"垂直"

给你两根不平行的箭 a 和 b，**叉积 `a × b`** 能造出一根**同时垂直于 a 和 b** 的新箭。

方向用**右手定则**确定：四指从 a 弯向 b，拇指指向结果。

长度 = a 和 b 张成的**平行四边形面积**。

### 2D 叉积：判"在左还是右"

在二维里，叉积退化成**一个数字**（正或负）——告诉你 b 在 a 的左边（正）还是右边（负）。

这就是三角形光栅化里**边函数的全部原理**：判断一个像素在每条边的哪一侧，三条边在同一侧 = 在三角形内部。

## 二、公式

### 3D 叉积

$$a \times b = (a.y \cdot b.z - a.z \cdot b.y,\quad a.z \cdot b.x - a.x \cdot b.z,\quad a.x \cdot b.y - a.y \cdot b.x)$$

记忆技巧：用三阶行列式展开：

```
| i  j  k  |
| a.x a.y a.z |
| b.x b.y b.z |
```

代码：`cross(a, b)`，返回一个新向量。

### 2D 叉积（标量）

$$a \times b = a.x \cdot b.y - a.y \cdot b.x$$

代码：`cross2(a, b)`，返回一个 float。

**符号含义**：

- 正 → b 在 a 的左侧（逆时针方向）
- 零 → 平行或共线
- 负 → b 在 a 的右侧（顺时针方向）

**为什么叫"有向面积"？** 因为 `cross2(a, b)` 的绝对值正好等于 a、b 张成的平行四边形面积的 2 倍，而符号表示旋转方向（逆时针为正）。"×2"在光栅化里无所谓——反正只比符号，但省一次除以 2。

## 三、叉积的性质（运算律，写代码时常用）

| 性质 | 公式 | 含义 / 用途 |
|---|---|---|
| 反交换律 | `a × b = −(b × a)` | **叉积顺序错了，法线方向就反了**（最常见 bug） |
| 与自身 | `a × a = 0` | 平行向量叉积为零 |
| 平行判定 | `a × b = 0` ⇔ a ∥ b | 判断共线 / 退化三角形 |
| 长度公式 | `|a × b| = |a||b|sinθ` | 面积的计算依据（sin 与点积的 cos 互补） |
| 分配律 | `a × (b + c) = a × b + a × c` | 公式推导的基础 |
| 与标量 | `(ka) × b = k(a × b)` | 提取系数 |
| 非交换 | `a × b ≠ b × a`（方向相反） | 与点积不同，叉积**不满足交换律** |

**和点积的关系**：点积含 cosθ（测"同向"），叉积含 sinθ（测"垂直/面积"）——两者互补。`dot` 回答"有多像"，`cross` 回答"围出多大面"。

## 四、渲染里的用途

### 造三角形法线

三角形三个顶点 v0, v1, v2，两条边做叉积：

```cpp
Vec3f e1 = v1 - v0;
Vec3f e2 = v2 - v0;
Vec3f faceNormal = cross(e1, e2).normalized();
```

这个法线的方向决定了光线打上去是亮还是暗——配合点积使用。

> ⚠️ 顺序敏感：`cross(e1, e2)` 与 `cross(e2, e1)` 法线反向。约定：**按顶点逆时针顺序取边**，法线朝外。

### 背面剔除

三角形法线如果朝向远离相机的方向，这个面就不可见，可以跳过不画——省掉约一半工作量。

判断方法：屏幕空间有向面积 `cross2(p1-p0, p2-p0) <= 0` → 背面，丢。

### 三角形光栅化（边函数）

这是叉积在渲染里**最频繁的调用**——每像素至少 3 次：

```cpp
// 边函数 E(p) = cross2(b - a, p - a)
// 对三角形的三条边各算一次
float e0 = cross2(p1 - p0, p - p0);
float e1 = cross2(p2 - p1, p - p1);
float e2 = cross2(p0 - p2, p - p2);

// 如果三个值同号，p 在三角形内部
bool inside = (e0 >= 0 && e1 >= 0 && e2 >= 0);
```

代码位置：`src/raster/triangle.h` 的 `barycentric` 函数和 `renderer.h` 的增量式边函数。

### 判断退化三角形

如果 `|cross(e1, e2)| ≈ 0`，说明两条边几乎平行或共线，三角形退化成一条线或一个点，应跳过。

### 构建正交基（相机、切线空间）

**只要两个不平行的向量，叉积就能造出第三个互相垂直的方向**——这就是所有正交基的来源：

```cpp
// 相机 lookAt 的 right 向量（forward 是视线方向，up 是世界上方）
Vec3f right = normalize(cross(forward, up));
Vec3f trueUp = cross(right, forward);   // 重新正交化，避免 up 不垂直
```

切线空间（TBN，法线贴图需要）：`normal = normalize(cross(tangent, bitangent))`。IBL 中生成反射采样方向同样依赖叉积造正交基。

### 混合积（标量三重积，体积）

$$(a \times b) \cdot c = \text{三向量张成的平行六面体体积}$$

一个点积 + 一个叉积的组合：先叉积造出"底面法线 + 面积"，再点积把高度投影上去。用途：判断三个向量的手性、空间点是否共面（体积 = 0）、包围盒测试。

## 五、代码入口

| 操作 | 代码 |
|---|---|
| 3D 叉积 | `cross(a, b)` → 新向量 |
| 2D 叉积 | `cross2(a, b)` → 标量 |
| 求法线 | `cross(v1-v0, v2-v0).normalized()` |
| 背面剔除判断 | `cross2(p1-p0, p2-p0) <= 0` |
| 求面积 | `0.5f * length(cross(a, b))` |
| 判断平行/退化 | `cross(a, b) == 0` |

## 六、动手实验

1. 在 `renderer.h` 找 `if (cullBackface && area2 <= 0) return;`，注释掉这一行——立方体会"内外都画"，背面盖住正面。理解剔除为什么省一半功耗。
2. 在 `triangle.h` 找 `cross2` 的调用，把 `e0 >= 0` 改成 `e0 > 0`——三角形边缘会出现 1 像素的缝隙，理解"等号"的重要性。
3. 在 `tests/test_core.cpp` 写一行：`EXPECT_NEAR(cross(Vec3f(1,0,0), Vec3f(0,1,0)).z, 1.0f, 1e-6f);`——X 轴叉 Y 轴得 Z 轴，验证右手定则。再试 `cross(Vec3f(0,1,0), Vec3f(1,0,0))`，z 变 −1，体会反交换律。

## 七、常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 叉积顺序写反 | 法线/判定方向全反（面朝里） | 按顶点顺序取边：`v1-v0` 再 `v2-v0` |
| 忘了单位化 | 法线长度 ≠ 1，光照亮度错 | `cross(...).normalized()` |
| 2D 叉积当 3D 用 | cross2 返回标量，无法取 `.x` | 区分 `cross`（3D 向量）与 `cross2`（2D 标量） |
| 平行向量做叉积 | 得到零向量，法线全黑 | 先检测 `|cross| ≈ 0` 跳过退化三角形 |
| 用点积求法线 | 点积是标量，方向信息丢失 | 法线必须用叉积 |
