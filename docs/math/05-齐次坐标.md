# 05 · 齐次坐标

> 3×3 矩阵表达不了"平移"。升一维成 (x,y,z,w)，w 既是"我是不是一个点"的标志，又兼职当"离相机多远"的载体。这是图形学最聪明的一个技巧。

## 一、问题

旋转和缩放是**线性变换**——满足 f(a+b)=f(a)+f(b)，原点不动。但**平移**把原点挪走了，f(0)≠0——3×3 矩阵乘零向量永远得零，永远表达不了"整体往右挪 3"。

## 二、解法：升一维

给坐标加第 4 个分量 w，变成 `(x, y, z, w)`：

- **点**用 `w = 1` → 平移生效
- **方向**用 `w = 0` → 平移自动失效（第四列乘 0）

平移量放在 4×4 矩阵的第四列。

```cpp
// 点会被平移
matrix.transformPoint(point);   // Vec4f(p, 1.0f)

// 方向不被平移——这正是我们想要的
matrix.transformDir(normal);    // Vec4f(d, 0.0f)
```

## 三、w 的第二重身份：距离

透视投影矩阵会把 `-z`（离相机的距离）写进结果的 w。之后的**透视除法** `(x/w, y/w)` 就实现了"除以距离"——近大远小。

也就是说，w 在平移阶段帮忙区分点和方向，在投影阶段又变成"距离的化身"。一个分量，两处妙用。

## 四、代码入口

`mat4.h`：

| 操作 | 代码 |
|---|---|
| 变换点（平移生效） | `m.transformPoint(p)` |
| 变换方向（不平移） | `m.transformDir(d)` |
| 构造 Vec4 点 | `Vec4f(v, 1.0f)` |
| 构造 Vec4 方向 | `Vec4f(v, 0.0f)` |
