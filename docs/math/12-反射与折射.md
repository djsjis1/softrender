# 12 · 反射与折射

> 镜面反射、水面倒影、玻璃折射、IBL 环境采样——都靠这两个公式。

## 一、反射 reflect

### 公式

$$R = I - 2(N \cdot I) \cdot N$$

其中：I = 入射方向（**指向**表面），N = 表面法线（单位向量）。

### 几何直觉

把 I 拆成"沿法线方向的分量"和"在切平面内的分量"。反射是**切线分量不变、法线分量取反**。

### 代码

```cpp
// I 指向表面，N 是法线（单位化！）
Vec3f R = reflect(I, N);  // vec.h
```

### 渲染用途

- **镜面 IBL**：`R = reflect(-V, N)`，然后用 R 采样 cubemap 得到反射颜色。代码在 `pbr_shader.h` 的 IBL 段落。
- **镜面反射**：水面、金属、玻璃的镜面效果。

## 二、折射 refract（Snell 定律）

### 公式

$$\eta = \frac{n_{incident}}{n_{transmitted}}$$

$$k = 1 - \eta^2 \cdot (1 - \cos^2\theta)$$

如果 `k < 0`：**全反射**，光线不会射出去（玻璃/水的掠射角）。

如果 `k >= 0`：

$$T = \eta \cdot I - (\eta \cdot \cos\theta + \sqrt{k}) \cdot N$$

### 代码

```cpp
float eta = 1.0f / 1.33f;  // 空气 → 水
Vec3f T = refract(I, N, eta);  // vec.h
if (T == Vec3f{0,0,0}) {
    T = reflect(I, N);  // 全反射，退回镜面反射
}
```

### 常用折射率

| 介质 | 折射率 (η) |
|---|---|
| 空气 | 1.0 |
| 水 | 1.33 |
| 玻璃 | 1.5 |
| 钻石 | 2.42 |

## 三、要点

- **I 指向表面**（不是从表面出发）。这是最容易搞错的约定。
- **N 必须单位化**。
- **全反射**是真实物理效果——泳池水面在掠射角时像镜子，就是这个原因。
- **折射率比**，不是绝对折射率。`空气→水` 是 `1/1.33`，`水→空气` 是 `1.33/1`。

## 四、动手实验

写一个小程序：给定入射角 45°、法线 (0,0,1)，分别算反射方向和折射方向（η=1.5）。验证反射方向是 (0.707, 0, -0.707)，折射方向偏向法线。
