# 06 · 模型变换

> 模型空间 → 世界空间。把物体从它自己的坐标系"摆"到场景里的某个位置。三个基本操作：平移、旋转、缩放。

## 一、模型空间 vs 世界空间

每个 3D 模型文件（OBJ/glTF）存的顶点坐标是**模型空间**——以物体自身中心为原点。一个立方体总是 `(-0.5, -0.5, -0.5) ~ (0.5, 0.5, 0.5)`，不管它被摆在世界的哪个角落。

**模型矩阵**负责把"物体自己的坐标"换算成"世界坐标"。三个基础操作：

$$Model = Translate \times Rotate \times Scale$$

## 二、每步的实际效果

| 操作 | 代码 | 效果 |
|---|---|---|
| 缩放 | `Mat4::scale(2, 1, 1)` | x 方向拉长 2 倍 |
| 旋转 | `Mat4::rotateY(π/4)` | 绕 Y 轴转 45° |
| 平移 | `Mat4::translate(5, 0, 0)` | 往右挪 5 单位 |

## 三、组合顺序

```cpp
// 先把 1x1 的立方体放大 2 倍，再绕 Y 转 30°，最后平移到 (3, 0, 0)
Mat4 model = Mat4::translate(3, 0, 0) * Mat4::rotateY(0.5f) * Mat4::scale(2, 2, 2);
```

## 四、法线需要特殊处理

法线用模型矩阵的**逆转置**变换，否则非等比缩放会让法线歪掉（不再垂直于表面）。

```cpp
Mat4 normalMatrix = model.inversed().transposed();
Vec3f worldNormal = normalMatrix.transformDir(modelNormal).normalized();
```

如果模型只有旋转+等比缩放，可偷懒用 `model.transformDir(normal)`。
