# 02 · 点积

> 点积是光照的核心——整个"亮暗"效果靠它。它回答两个问题：两个方向有多"同向"？一个向量在另一个方向上投影多长？

## 一、直觉

想象太阳光照在你脸上。正对太阳 → 脸最亮；侧面 → 暗一些；背对太阳 → 完全黑。

**"脸朝向"和"光来的方向"之间的夹角，决定了亮度。** 而点积就是测这个夹角的工具。

点积的第二个直觉：**投影**。一根旗杆斜插在地面，正午阳光把它"压"成一个影子。影子的长度 = 旗杆在"阳光方向"上的投影。点积算的就是这个影子长度（乘上参考长度）。

## 二、两种定义（它们是等价的）

### 代数定义（坐标形式，代码里的样子）

两个向量 `a = (a.x, a.y, a.z)` 和 `b = (b.x, b.y, b.z)` 的点积 = **对应分量相乘再求和**：

$$a \cdot b = a.x \cdot b.x + a.y \cdot b.y + a.z \cdot b.z$$

结果是一个**标量**（一个数），不是向量。**代码里 100% 按这个算**。

### 几何定义（含义形式，脑子里的样子）

$$a \cdot b = |a| \cdot |b| \cdot \cos\theta$$

其中 θ 是两向量的夹角，`|a|` 是 a 的长度。

**为什么相等？** 用余弦定理可以证明：把 `|a−b|²` 用两种方式展开——一边是 `(a.x−b.x)²+(a.y−b.y)²+(a.z−b.z)²`，一边是 `|a|²+|b|²−2|a||b|cosθ`，一对比就得到 `a·b = |a||b|cosθ`。所以**代数定义和几何定义是同一件事**：分量相乘再求和，恰好等于"长度 × 长度 × 夹角余弦"。

### 关键简化：单位向量时

当 a 和 b 都是单位向量（长度 = 1）时，`|a|·|b| = 1`，于是：

$$a \cdot b = \cos\theta$$

所以：

| 夹角 θ | cosθ = a·b | 在光照里 |
|---|---|---|
| 0°（同向） | 1 | 最亮 |
| 90°（垂直） | 0 | 完全不亮 |
| >90°（反向） | 负（取 0） | 黑 |

### 具体例子

法线 N = (0, 0, 1)（朝 Z 正方向），光方向 L = (0, 0, 1)（光也朝 Z）：

$$N·L = 0·0 + 0·0 + 1·1 = 1 \quad\Rightarrow\quad \cos\theta = 1，\theta = 0°, 最亮$$

如果光从侧面来，L = (1, 0, 0)：

$$N·L = 0·1 + 0·0 + 1·0 = 0 \quad\Rightarrow\quad 垂直，不亮$$

## 三、点积的性质（运算律，写代码时常用）

| 性质 | 公式 | 用途 |
|---|---|---|
| 交换律 | `a·b = b·a` | 调换顺序结果不变 |
| 分配律 | `a·(b+c) = a·b + a·c` | 公式推导的基础 |
| 与标量 | `(k·a)·b = k·(a·b)` | 提取系数 |
| 与自身 | `a·a = |a|²` | **求向量长度的捷径**（代码里 `lengthSq` 就是这么写的） |
| 柯西-施瓦茨 | `|a·b| ≤ |a||b|` | 即 cosθ 范围永远在 [−1, 1]；溢出说明算错了 |
| 正定性 | `a·a ≥ 0`，等号当且仅当 a = 0 | 长度永远非负 |

## 四、几何含义的三种用法

**1. 测夹角（同向程度）**：`dot(normalize(a), normalize(b))` = cosθ。光照亮度、颜色匹配度判断。

**2. 算投影长度**：`dot(a, unitB)` = a 在 b 方向上的投影长度（有符号）。公式：

$$\text{proj}_b(a) = \frac{a \cdot b}{|b|^2} b$$

投影是后续一切正交分解（Gram-Schmidt 正交化、构建正交基）的基石。

**3. 判断朝向**：`dot(cameraForward, toObject)` > 0 → 在前；< 0 → 在后。`dot(a, b) == 0` → 两向量垂直（正交）。

## 五、渲染里的用途

### 漫反射光照（Lambert）

核心公式一行：

```cpp
float brightness = max(0.0f, dot(normal, lightDirection));
```

`max(0, ...)` 确保背光面不发光（不产生负亮度）。在 `pbr_shader.h` 里找 `dot(N, L)`——这就是漫反射的全部秘密。

### 镜面高光（Blinn-Phong 半程向量）

镜面反射不再直接点积 `R·V`，而是构造**半程向量** `H = normalize(L + V)`，然后：

```cpp
float spec = pow(max(dot(N, H), 0.0f), shininess);
```

H 与 N 越接近（点积越大），高光越亮；`shininess` 控制高光锐利程度。点积在这里再次充当"夹角探测器"。

### 判断朝向 / 背面

`dot(cameraForward, toObject)` > 0 表示物体在相机前面；< 0 表示在背后（可以跳过渲染）。视锥剔除、远近排序都依赖这种判断。

### 反射向量（与点积的深层关系）

```cpp
Vec3f reflect(I, N) { return I - N * (2 * dot(N, I)); }
```

`dot(N, I)` 算出 I 在法线方向的分量，翻倍后减去——把入射方向"镜像"过去。**点积负责"分解出法线方向分量"，减法负责"翻转"**。这是 IBL 环境反射、水面倒影的数学基础（详见 `12-反射与折射.md`）。

### 正交基 / 投影（高级预告）

把向量分解成"平行于某方向 + 垂直于某方向"两部分：

```cpp
Vec3f parallel   = N * dot(N, v);          // v 在 N 上的投影
Vec3f perpendic  = v - parallel;           // 剩余部分，垂直于 N
```

这是 Gram-Schmidt 正交化、切线空间（TBN）构建、IBL 中把向量投影到切平面采样的基础。

## 六、代码入口

```cpp
#include "math/vec.h"

Vec3f N{0, 0, 1};           // 法线（单位化！）
Vec3f L{0.4f, 0.7f, 0.5f}; // 光方向

// 别忘了单位化！
float diff = std::max(0.0f, dot(N, L.normalized()));
```

**通用版 dot**：项目里的 `dot(a,b)` 支持 Vec2/Vec3/Vec4 任意维度，利用了编译期常量 `size` 和 `operator[]`，一份代码覆盖所有：

```cpp
template <typename A, typename B>
auto dot(const A& a, const B& b)
{
    static_assert(A::size == B::size, "dot: 两个向量的维度必须一致");
    using T = decltype(a.x);
    T sum = T(0);
    for (int i = 0; i < int(A::size); ++i)
        sum += a[i] * b[i];
    return sum;
}
```

循环边界是编译期常量，优化器会完全展开，性能和手写逐分量乘法一致。

## 七、动手实验

1. 在 `pbr_shader.h` 找到 `float NdotL = std::max(dot(N, L), 0.0f);`，把它改成 `float NdotL = 1.0f;`——所有面都一样亮，立体感消失。
2. 把光方向的单位化去掉（`dot(N, L)` 而非 `dot(N, L.normalized())`），看亮度随光向量长度变化。
3. 在 `tests/test_core.cpp` 写一行：`EXPECT_NEAR(dot(Vec3f(1,0,0), Vec3f(0,1,0)), 0.0f, 1e-6f);`——垂直向量点积为 0，验证直觉。

## 八、常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 法线没单位化 | 亮度被法线长度放大 | 用 `.normalized()` |
| 光方向没单位化 | 亮度随光源距离变化 | 单位化 |
| 忘记 max(0, ...) | 背光面"负亮度"出现鬼影 | 加 `max(0.0f, ...)` |
| 点积结果 > 1 | 说明输入没单位化（|cosθ| 永远 ≤ 1） | 检查 normalize |
| 把点积当向量用 | 点积返回标量，不能再 `.normalized()` | 区分 dot（标量）与 cross（向量） |
