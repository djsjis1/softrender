# 08 · 透视投影

> 相机空间 → 裁剪空间。核心问题：怎么把"近大远小"用矩阵表示？矩阵做不了除法，但它能把距离塞进 w，让后面的 ÷w 完成这件事。

## 一、相似三角形：透视的几何来源

相似三角形告诉我们，点 (x,y,z) 投影到近平面 z=-n 上的坐标是：

$$x' = \frac{n \cdot x}{-z}, \quad y' = \frac{n \cdot y}{-z}$$

分母是 -z——距离越远，值越大，除完就越小。这就是**近大远小的全部来源**。

## 二、矩阵做不了除法 → 把除法推迟

我们不直接算 x/(-z)，而是构造一个矩阵，让它的结果满足：

- `x_clip = x`（不变）
- `w_clip = -z`（把距离装进 w）

之后做**透视除法** `x_clip / w_clip = x / (-z)`——除法自动完成。

这全靠矩阵的**最后一行**，代码里就是 `transform.h` 的 `m[3][2] = -1.0f`——整个透视投影最关键的一行。

## 三、剩余的行

```cpp
Mat4 p;
p.m[0][0] = 1.0f / (aspect * tan(fovY / 2));  // x 归一化
p.m[1][1] = 1.0f / tan(fovY / 2);              // y 归一化
p.m[2][2] = -(f+n) / (f-n);                    // z 映射到 [-1,1]
p.m[2][3] = -2*f*n / (f-n);
p.m[3][2] = -1.0f;                             // w = -z（最关键）
```

其中：`fovY` = 垂直视场角（如 45°），`aspect` = 宽/高，`n/f` = 近/远平面。

## 四、动手实验

在 `stage3_cube.cpp` 把 `perspective` 的 `m[3][2] = -1` 改成 `0`——透视消失，所有物体一样大，像工程图。
