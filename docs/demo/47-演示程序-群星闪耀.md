# 47 · 演示程序：群星闪耀

> 用软渲染器纯 CPU 生成 1920×1080 星空图，展示 HDR 渲染 + 色调映射 + 程序化效果的能力。

## 一、效果组成

| 层 | 技术 | 说明 |
|---|---|---|
| 星云背景 | FBM 分形噪声 | 紫蓝+橙红双色，5 层 octave |
| 暗星 ×800 | 高斯衰减点 | 不同色温（蓝/白/橙），半径 0.3~0.9px |
| 亮星 ×80 | 高斯 + 外层光晕 | HDR 强度 1~4，半径 1~2.5px |
| 超亮星 ×12 | 多层高斯 + 十字衍射 | HDR 强度 5~15，衍射光芒 30~90px |
| 色调映射 | ACES 近似 | HDR→LDR，亮星不过曝 |
| Gamma | sRGB 2.2 | 线性→显示 |

## 二、关键技术点

- **FloatFramebuffer**：所有星星用加法混合累积到 HDR 缓冲，亮度可超 1.0
- **高斯衰减**：`exp(-dist²/(2σ²))` 模拟点扩散函数
- **十字衍射**：4 条线（0°/90°/45°/-45°），立方衰减 + 宽度随距离缩小
- **FBM 噪声**：多层 value noise 叠加，模拟星云的不规则结构
- **色温映射**：随机温度 → 蓝白/白/橙红 RGB

## 三、运行

```bash
./build/bin/Release/demo_stars
# 输出：output/stars.tga (1920×1080)
```

## 四、对应代码

`examples/demo_stars.cpp`

## 五、性能

1920×1080 = 207 万像素，星云背景逐像素 FBM（5 octave）约 2 秒，星星绘制约 0.5 秒，色调映射约 0.3 秒。总计约 3 秒（单线程 Release）。
